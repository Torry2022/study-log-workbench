# 架构

`study-log-web/app` 使用 Next.js App Router 提供 `/study-log` 入口。根布局在首次绘制前初始化主题；基础CSS注册三个本地字体族，原始字体与许可证作为静态资源提供。

认证API使用实例密码校验和HMAC签名；Cookie与App Token按受众区分。能力接口读取实例身份、聊天配置及模板状态，不产生资料写入。日志读写、整理、AI 写作与日志问答已接入；各自的验收边界见[实施状态](implementation-status.md)。

`AuthGate`负责认证生命周期，`LoginScreen`仅持有密码、提交中和错误状态。认证过期保留工作区组件实例并隐藏内容；重新认证后恢复，主动退出则卸载清理。共享JSON请求在会话变化时取消，并在解析响应后检查取消状态，避免不遵守取消的旧响应回灌。业务模块从会话上下文读取活动状态，并分别验证草稿与流的生命周期。

`ops/instance.mjs` 负责实例初始化。它只操作显式传入的绝对目录，识别已有身份，使用独占创建保留原配置。`ops/run-web.mjs`读取选定实例环境，强制数据根为该实例的data目录；它与standalone入口`ops/serve.mjs`共用服务监督器，持有含随机归属的运行锁直到子进程正常退出。异常停止保留锁，维护只释放自己拥有的锁。Linux真实SIGTERM及子进程异步收尾测试通过；问答长流和完整部署停机仍待对应批次验证，见[维护边界](maintenance.md)。

## 数据边界

MCP 的只读基础由 `paths` 验证显式且不重叠的 `LOG_ROOT` / `INDEX_ROOT`，`markdown-source` 按 AST 根标题解析真实年月文件，`log-store` 提供日期与来源读取。`KeywordRetriever` 保留 BM25F、同小节合并、重复内容过滤、字面匹配和三种上下文排序；纯关键词路径不联网、不创建索引，不读取随记、Wiki或附件正文。`HybridRetriever` 可叠加独立配置的向量和重排；故障回退第一阶段结果并说明诊断。缓存身份核验持久实例UUID、路径、端点哈希、模型、维度及切片版本，进程内串行、完整临时文件原子替换，失败保留旧缓存。只读 MCP 协议和 Web 问答已接入；真实向量及重排提供方尚未验收。

词法检索将 `5%` 等单数字百分比作为完整词项保留，避免混合主题问题只召回泛泛提及“灰度”的旁记。Web 在 `done` 中按方括号引用首次出现顺序同时重排来源列表与正文引用；若回答另有裸写的来源编号，也按同一映射调整，代码和链接保持原文。该机械一致性不验证来源是否真的支持模型结论。

只读链为API鉴权→参数及源文件校验→Markdown根级标题解析→日块/目录结果。`day-content`使用Markdown AST处理围栏和嵌套内容，日期及小节共享同一种根标题语义；`log-store`管理文件枚举、按内容校验的解析缓存和版本快照。只读方法不创建资料，错误处理保留可操作的结构错误并隐藏底层文件系统细节。

源码仓仅保存代码、公开资源与合成测试；用户资料和配置属于显式指定的实例目录；索引是可重建数据，备份是独立恢复资料。后续实现不得依赖源码父目录寻找资料。

附件只读入口经合成目录测试验证根目录/子级链接隔离及打开期间目录替换，Windows文件符号链接测试因系统权限跳过；目录联接场景已实际执行。部署目标Linux的链接测试仍须在部署批次执行。该检查不把拥有实例目录写权限的本机用户视为可信隔离沙箱。

## 阅读目录语义

分类建议的 `useTaxonomySuggestions` 只管理请求和待审核建议，`useStats` 继续持有唯一分类草稿。请求只基于已保存领域；手工编辑会取消旧请求并作废旧建议。应用前再次读取保存版本进行比较，不以新快照覆盖用户草稿；审核选中的建议只合并入草稿，后续保存仍由现有版本化分类接口处理。

普通搜索直接读取权威日块，按字面逐行匹配；标题范围复用AST根级H3语义，不依赖派生检索索引。搜索框维护查询、取消与键盘选中，父工作区负责草稿保护和选中后的高亮定位；搜索历史最多8项，显式退出清空，过期重登保留。手机与桌面复用同一个搜索组件，避免隐藏组件发请求或争夺焦点。

正文目录复用日块解析器的Markdown AST根级标题结果（H2–H6），不再另行切换围栏布尔值；围栏字符/长度、列表嵌套和引用均由同一语法树处理。目录保留行号，并对重复标题生成稳定的递增锚点。

## 客户端职责

`useRag` 管理流式回答与版本化会话保存，`RagWorkspace` 负责正文、引用及新回答自动跟随，`RagHistorySidebar` 负责历史筛选、弹层和内部列表滚动。`useLogWorkspace` 维护 `view=qa` 与会话 URL；根工作区统一处理离开确认及引用跳转。移动抽屉的实际可见状态传给历史组件，隐藏时不创建弹层、争夺焦点或滚动当前会话。

RAG 的检索规划、MCP 边界校验、回答流解析和历史存储分别独立。规则规划器先把显式日期条件转成范围，连续并列的多个完整日志日期必须涵盖首末及中间所有日期；无效日期不回退成仅检索首日。MCP 只在该范围内检索，故规划错误会让真实日志在回答模型之前消失。服务端只在提供方完整结束后发 `done`；客户端再次核验结束事件和来源结构，EOF 不代表成功。历史请求保存稳定操作身份与会话版本，未知结果不会清稿。自动标题不能覆盖手动标题，也不能用迟到响应偷偷推进另一个对话快照的版本。

`useWriting` 管理材料、补充要求、生成稿和请求代次；右侧栏折叠保留内容，日期/认证/模块变化中止旧请求。根工作区在确认离开后统一丢弃日志及 AI 草稿，单独“放弃日志修改”不影响材料。应用生成稿前再次核验日期和编辑状态，只追加到编辑器，复用现有保存事务。`WorkspaceChrome` 只控制侧栏宽度和手机抽屉；工具栏依据阅读容器宽度布局。

材料解析与模型请求分离：`upload-extract` 只解析有界文本，不保存上传原件；`ai-generation` 组合实例模板、有限的当日日志与近期标题；`ai-chat` 负责超时、取消、响应大小和安全错误。生成结果经 Markdown AST 验证，不能引入其他日块或吞掉相邻日块的未闭合根围栏。模板负责写作偏好，存储层继续负责文件结构；不内置个人 Skill 或固定写作风格。

`highlight-ranges` 从 Markdown AST 的可标注文本提取原始偏移和 token 身份，模型只能选择范围，服务端只插入粗体标记并核验实际解析结果。`useHighlighting` 保留请求时的日期与原文；审阅对话框应用前和根工作区写稿前各核验一次快照。关闭、认证失效或模块变化只取消审阅，不改源文；应用结果继续使用日志编辑器的显式保存。

`useNotes` 维护随记列表、筛选和编辑基线；正文、心得、来源与标签分别保存。提交时复制稿件，响应只推进该次保存的基线，期间新输入保留为未保存修改。图片插入记录字段和选区，输入时映射位置；取消、放弃、认证变化后迟到上传不能进入新稿。随记读取与保存取消相互协调，旧列表不能覆盖成功写入。来源往返保留仍适用的筛选，指定随记深链在必要时清筛选并展开定位。

鸿蒙随记控制器在写入成功或核对确认成功时，先把该条结果应用于当前列表与年份／标签计数，再发起列表刷新；刷新失败保留已知写入结果并显示可重试的读取错误，不能让旧卡片冒充当前服务端状态。

鸿蒙工作台保留随记页挂载；每次从其他模块切回随记时由工作台递增回访修订号，页面只重读随记列表与筛选元数据，不重建编辑会话。编辑中的内容及版本基线仍由 `NoteEditorSession` 持有，另一设备改写同一条随记时继续由保存时的版本冲突处理。

`useExport` 只下载已保存资料；未保存稿先明确确认，下载不改变编辑状态。Blob 读取与 JSON 请求共用认证代次，日期、模块、认证变化或显式取消均中止迟到下载。`ExportMenu` 提供桌面菜单及手机操作项，根工作区呈现进度和可重试错误。四类内容导出按原文件组织附件，不等同于包含配置、收藏和历史的整实例备份。

统计由 `stats-store` 从权威日志计算，根级 H3 及真实日块决定计数；只有“其他”是内置领域。`taxonomy-store` 的完整快照版本保护用户自定义映射，写前唯一备份，临时文件替换。`useStats` 分开管理月度读取和分类草稿，迟到月份请求不能替换当前月；409、读取失败和认证过期不覆盖未保存映射。图表钻取传回日期和实际标题序号，由工作区核验后定位原文。

收藏记录独立于原日志，保留日期和H3标题身份；来源失效只改变解析状态，不删除收藏。元数据写入与快照读取共用实例内队列，避免Windows读取与rename冲突。一个`useFavorites`管理目录星标、中心和侧栏的共享状态，成功写入先更新本地快照再刷新；刷新失败仍保留写入结果。导航选择包含当前模块，切模块及历史返回复用草稿保护。隐藏日志阅读器保留编辑实例，但停止滚动定位、尺寸测量和快捷键，避免影响当前模块。

收藏分组复选操作只向服务端提交单个分组的加入或移除，由实例内写入队列在当前快照上合并，避免两个客户端按各自旧快照提交完整数组时互相覆盖。原有完整数组 PATCH 仅保留旧客户端兼容；它本身仍不提供并发保护。

`WorkspaceChrome`只负责导航壳与响应式控件；`useLogWorkspace`持有月份、日期、取消和URL状态；`LogReader`负责阅读定位和目录；`MarkdownPreview`统一渲染正文及后续问答。读取期间导航列表仍可切换，迟到响应不能回灌。浏览器历史保存来源滚动位置，内部链接使用稳定标题ID或原文标题定位。会话过期隐藏的业务树在重登后重新读取。

## 编辑与版本事务

加载、空白和读取失败共用 `components/WorkspaceState.tsx`，包括认证、日志预览/源码、随记、收藏、统计和问答。调用方提供状态、内容及重试操作，既有容器样式决定位置：日志加载仍在正文起点左对齐、旋转图标位于文案右侧，模块空态使用内容区居中规则；不把所有场景强制改成同一坐标。

`useNoteCandidates` 在根工作区常驻，负责材料选择、顺序解析、提取结果和待确认的批量保存快照。提取结果使用服务端 UUID，新增标签须人工确认；保存开始后锁定原批次，未知结果及认证中断不改变身份或内容，只有核对返回记录后才清稿。`createStudyNotes` 在现有随记队列中核对 UUID 和规范化业务字段，重复请求复用原记录，新增记录统一进入现有年度写入流程。候选界面负责审核，不能直接修改分类或自动写入日志。

`LogEditor`持有同一日期的CodeMirror实例与撤销历史；`useLogDraft`管理正文、已保存正文、版本及保存状态；`useLogWorkspace`负责导航和读取，列表刷新与正文重新读取分开。保存响应仅更新提交时的基线，保存期间的新输入仍是未保存草稿。离开确认置于业务导航边界，浏览器后退取消后恢复已接受的历史位置。

重复选择当前月份是幂等操作，保留当前日期、标题定位和未保存草稿，不依赖重新请求日期列表来恢复选择。收藏目标缺失以独立的可空状态记录，离开对应日期后清除，不能把空日期当成缺失收藏。

日历和侧栏等待日期导航的接受结果，再关闭浮层并清除筛选；取消离开时保留原上下文。离开确认拥有最上层的键盘焦点和 Escape，底层日历、手机抽屉不提前消费该操作。

普通日志日期跳转先保存来源滚动位置，再在加载开始前回到页面顶部。这样加载态与完成态的工具栏边线处于同一坐标；指定小节跳转及浏览器历史仍由阅读器在目标就绪后定位。

`useReadingPosition`在布局切换前捕获源码偏移，切换后对应Markdown渲染块或编辑器行恢复；无法映射时才按滚动比例回退。它不持续监听滚动，不引入双向滚动同步。正文内部链接回调保持稳定，目录高亮更新不会使Markdown组件重建。

写入在实例内串行，`baseVersion`必须明确传入，null只表示目标日不存在；字符串比较完整源文件快照。`log-store`决定年/月归属并保留其他日块字节，替换前创建唯一完整文件备份，再以同目录临时文件rename提交。备份根由实例启动器明确指定；错误不回传本机路径。追加、删除及日块恢复共用此事务，不直接复制整月备份覆盖当前资料。

`useEditorAttachments`保留上传时的文档与插入选区，通过CodeMirror变化映射原位置；日块、会话、模式或显式草稿重置变化取消操作。图片成功后作为一个可独立撤销的编辑事务插入，不自动保存。服务端先验证整批元数据和体积，再生成唯一附件名，失败仅回收本次创建且身份可确认的文件。

普通内部链接使用原始日志作为来源。选择器负责搜索、别名和键盘交互；同一日块出现同名小节时，候选携带现有大纲的唯一标题 ID，插入时以该 ID 为目标、原标题为显示文字，其他链接继续使用标题。阅读器先按 ID 定位，再按原有编号／标题规则回退，并恢复来源位置；它不依赖 Wiki。标题 ID 由当前文档生成，后来重命名或调整同名标题顺序可能使链接回退到标题匹配，并非持久锚点。链接弹层挂到文档根，避免阅读器容器限制手机窗口宽度。

`day-backup-store`负责历史版本枚举、日块去重和预览；恢复同时检查历史摘要与当前源版本，并交回`log-store`写事务。`BackupDialog`持有预览/请求状态，父工作区确认稿件丢弃并在成功后接收新日块。弹窗的滚动锁与背景inert按使用次数释放，保证嵌套弹窗在认证失效时任意卸载顺序都能还原页面。

## 鸿蒙客户端当前边界

工作台当前模块由 `Index.selectedModule` 唯一持有，日志工作区通过 `@Link` 接收，不再以四个模块布尔值拼接选择状态。顶栏、底部导航、收藏／统计来源、随记链接及问答引用都经过同一离开确认和模块过渡入口；更换服务器的离开检查不预先改变当前模块。后续职责恢复清单见 `harmony-workspace-recovery.md`，当前工作台宿主直接装配应用层外壳及常驻日志模块。

`app/components/WorkspaceFrame` 承接原版 `Index.workspace` 的顶栏／导航布局、模块区域、底部导航及模块截图覆盖层；通过构建器参数接收现有内容。`Index` 持有 `WorkspaceModuleState`、收藏控制器和问答导航控制器；`app/components/WorkspaceContent` 持有五模块常驻容器，日志正文和日志侧层通过构建器接入。顶栏和导航由应用层装配；日志内容及日志内层由 LogsReaderPage 管理。文档与阅读模式截图继续挂在工作台根层，不能移入模块覆盖层。迁移保留原版顶栏父层级、模块焦点入口及阅读模式隐藏控件处理。

公开鸿蒙端使用连接时选择的实例 origin 与 App Token；`ApiClient` 在响应返回前核对实例和会话代次。日志阅读、版本写入、附件上传、内部链接、搜索与导出均使用公开 Web/API 契约。`LogSession` 持有当前日块与源码草稿，`LogNavigationController` 持有列表与日历状态；离开前通过同一编辑器快照检查未保存修改。ArkWeb 阅读页带令牌请求当前实例图片，附件 GET/OPTIONS 支持跨源预检但 GET 仍要求认证；点击已加载图片交由原版图片预览组件显示。统计、收藏与随记沿用个人版页面和导航组件，分别适配公开 `/stats`、`/favorites`、`/notes` 契约；随记编辑由 `NoteEditorSession` 保存基线，模块切换检查未保存状态。窄屏沿用原版顶栏和底部模块导航，当前模块的导航内容装入侧层；搜索历史复用原版列表组件，按公开实例命名空间保存在设备本地；本机阅读与编辑偏好由 `WorkspacePreferences` 保存。

日志 AI 生成与重点标注使用公开实例服务，在日期及编辑器快照核对后仅修改未保存草稿。随记候选保留原版审阅界面，但先经 `/materials/extract` 逐份解析，再向 `/notes/candidates` 发送材料 JSON。鸿蒙普通新建／编辑及候选批量保存均在当前生命周期内核对返回记录数量与请求 ID，候选逐项按输入顺序核对；未确认的响应不清稿，明确重试沿用原 ID。问答页面沿用原版结构，`ApiClient` 提供可取消的实例隔离 SSE；会话控制器只有收到 `done` 才视为完整，历史写入携带版本和稳定操作 ID，未知结果重试不重复调用模型。PC、平板、手机的具名操作链、键盘及布局／过渡专项已有迁移记录，采样间隙和未覆盖组合仍保留；`study-log-harmony` 的构建及纯逻辑测试不替代设备证据或独立安装验收。独立签名和异网络受信 HTTPS 是发布前待验条件，当前无法提供外部条件，不据此阻止本地源码与文档收尾，也不标记它们通过。


日志工作台的左右侧栏共用标题栏目标宽度与操作槽位插值，避免侧栏逐帧调宽时标题栏跨断点突然重排。右侧 dock 负责系统底部背景及分隔线；AI 表单单独滚动，固定操作区保留按钮自身的圆角、边框和两侧留白；窗口入口发布实际底部系统避让量，操作区只补足 16vp 最小底部留白，避免无避让的 PC 窗口贴边和移动端重复留白。输入聚焦时由系统 RESIZE 处理键盘避让，并保留按钮与键盘间距。五模块共用展开／收起框架，浮层复用各模块导航组件；模块切换清除旧浮层并使旧动画回调失效。展开偏好按模块保存在本机设置，连接工作台前等待设置恢复并再次检查实例代次。统计手工分类管理已迁入，多设备视觉验收状态见迁移记录。

模块内容现沿用原版的常驻挂载方式，日志阅读器在切到其他模块后仍保持就绪。宽屏模块切换复用原版 `WorkspaceTransitionCoordinator` 的画面保留与渐隐，窄屏复用旧模块留场、新模块渐显的状态；切换请求在未保存内容的离开决定之后执行。随记和问答确认放弃时显式清除仍挂载页面的编辑稿，不依赖卸载页面清理状态。该结构只处理模块切换；日志文档和浏览／编辑模式的过渡仍单独验收。


鸿蒙分类管理沿用个人版页面结构，由 `TaxonomyController` 管理公开接口的分类快照与生命周期；只使用实例自定义领域和保留分类“其他”。写入携带 `baseVersion`，409 保留草稿并要求明确重读，保存过程中禁改，卸载后忽略迟到响应。AI 分类建议按当前筛选的 1 至 200 个标签向 `/taxonomy/suggest` 请求，只在已保存自定义领域且没有分类草稿时可用；结果按原保存版本核对、筛除无效标签和领域，供用户逐项选择和改领域。应用前重新读取服务器版本，只把所选项合入未保存草稿，最终仍由现有分类保存操作写入。手工修改或重新读取使旧建议失效。`Index` 统一管理分类页的返回、模块切换及更换服务器保护，分类保存后刷新月度统计。


日志文档状态归 `features/logs/LogSession` 持有，沿用原版日块／草稿／保存基线职责及脏状态判断。公开版额外保存草稿基准版本；日期键、显式编辑器替换、读写代次与响应丢失核对继续使用公开实现。工作区组件通过会话访问文档，导航和编辑器渲染状态没有合入会话；`LogDocumentController` 已承接日块读取、请求代次、加载状态与保存事务，通过绑定回调连接编辑器与页面，并在卸载时解绑。月份／日期列表及日历由 `Index` 持有的 `LogNavigationController` 管理，与文档控制器共用读取仓库，页面绑定快照、打开日块及错误反馈。完整组件边界仍待恢复。

非日志模块的筛选、草稿／忙碌标志、加载位置及返回顶部请求由工作台状态统一持有；导航与页面通过同一可观察对象读取，收藏和问答控制器另用 `@ObjectLink` 保持内部状态更新。连接成功时重建这一组模块状态，退出或认证失效时递增问答请求代次并释放收藏请求；问答回调捕获所属状态对象，不能写入后来的实例状态。分类管理宽屏内容与窄屏覆盖层共用应用层组件，遮罩位置与过渡参数保持原布局。

桌面顶栏布局与响应式密度由应用层 `DesktopWorkspaceTopBar` 管理，搜索输入、候选及更多菜单由该组件自身构建，行为通过 Index 绑定的工作台命令执行。顶栏品牌按钮、模块按钮及主题面板已直接迁入个人版实现，保留焦点／悬停／选中样式和主题选择后关闭行为；公开模块表不含进阶模块，退出适配为受离开保护的更换实例。设置／关于仍由更多菜单进入。搜索控制器和 F6 区域焦点编排由 Index 持有，普通按键与编辑器命令共用入口；设备验收范围见工作台恢复清单。


`WorkspaceModuleNavigation` 在应用层装配非日志模块的展开导航、收起浮层和窄屏抽屉内容，共享 `Index` 的模块状态及收藏／问答控制器。日志月份／日期导航由应用层 WorkspaceLogNavigation 接入；切换会话、删除会话、分类管理和关闭抽屉仍委托原有离开保护入口，未重写业务。导航外框、标题、收起工具栏及浮层绑定由应用层 `DesktopWorkspaceNavigation` 持有；共享收展编排由 Index 持有，日志工具栏通过视图回调同步。


全局搜索由 `Index` 持有 `WorkspaceSearchController` 与展开状态，界面读取同一可观察控制器；搜索请求继续走公开 repository，历史使用实例 namespace。关闭、条件改变、实例失效均废弃旧结果，恢复历史受独立代次保护。桌面候选使用原版 `GlobalSearchCandidates`，结果选择仍进入公开版的日志离开确认与目标导航；候选布局测量在 DesktopWorkspaceTopBar，区域焦点编排在 Index。

月份刷新、日期列表和日历具有独立请求代次；选择日期列表时使旧月份刷新失效，防止迟到刷新覆盖新选择。跨月日块失败仍回滚原月份及列表，重试整个目标导航；卸载和实例退出解绑旧请求。


跨模块日志来源携带目标日期，沿用原版待就绪／揭示机制：目标预览或当前可见源码编辑器报告就绪后结束模块过渡，读取失败则揭示保留的日块与错误反馈。新模块请求废弃旧过渡帧；日块读取不清掉仍在覆盖的模块画面。搜索来源与随记／收藏／问答／统计来源共用离开保护。五个模块容器均设置设计规范的画布背景，避免截图合成时透明区域露出目标控件。


日志目录恢复原版唯一活动小节状态、桌面目录构建器和正文滚动后的列表跟随；延后执行的目录滚动同时核对文档请求代次、日期与生命周期，切换文档或隐藏目录后不执行旧滚动。同名小节的定位继续使用公开索引参数，控件 ID 则使用现有解析器的唯一标题 ID。


`Index` 现持有模块切换／离开确认、问答会话导航与删除确认、分类管理入口及 `WorkspaceTransitionCoordinator`。`WorkspaceNavigationBridge` 仅连接日志页的就绪、离开和视图关闭能力；每次绑定有身份校验，防止旧页面、旧弹窗和延迟焦点操作新实例。最终装配方向为 Index → WorkspaceSurface → 常驻日志模块；阅读目录、内部链接和 AI 标注审阅等日志功能弹层由日志模块持有。窗口键盘避让统一由根页面设置 RESIZE，输入框不再在失焦时恢复窗口 OFFSET；问答明确接受会话切换才清空草稿，单纯读取失败重试不清空草稿。


阅读模式状态和截图／视口过渡由 Index 持有，日志页通过已绑定的工作台命令报告可进入条件、视口和就绪。窗口断点由应用层决定，缩窄时撤销阅读模式；迟到截图及动画完成不能恢复已撤销的状态。图片的原始栅格尺寸与覆盖区域尺寸继续分开，使用原有协调器等待动画和正文双就绪。


侧栏收展偏好、动画进度和代次由 Index／WorkspaceSidebarState 管理；组件只读取状态并报告操作，日志工具栏宽度同步和日期列表定位通过绑定视图回调完成。模块切换和实例解绑在应用层使动画帧失效，避免旧帧改变新模块的布局。

编辑器的工作台命令按原版回传 Index：帮助、区域焦点、桌面菜单及新建日志／问答复用应用层入口。普通按键和编辑器 F6 共用应用层焦点序列；桥接绑定失效或弹层阻断时不能执行命令，新建入口继续经过既有离开确认。保存与内部链接仍由日志功能持有。大纲打开时通过原有 MarkdownReader 的请求代次重新测量活动标题，源码态使用首个标题；展开和关闭回调检查页面生命周期。

ArkWeb 阅读区获焦时，键盘事件从共享 MarkdownReader 经日志或问答页面回传 Index 的同一工作台快捷键处理器；未处理的按键仍交给 Web 内容。这样浏览与问答正文不再依赖 Web 事件向外层自动冒泡，弹层和实例保护继续由 Index 统一判断。


备份弹层沿用原版 AppModalFrame／宽屏 bindContentCover／紧凑标题上的 bindSheet，由日志功能管理开启和恢复忙碌状态。预览读取完成不等于 Web 绘制完成，初次揭示等待正文阅读器同样的双动画帧通知，并拒绝旧生命周期或旧版本通知。API 的当前版本、备份版本和恢复前确认不变。


WorkspaceSurface 在应用层装配 WorkspaceFrame、WorkspaceContent、全局提示和截图覆盖，按原层级接入日志与导航构建器。Index 直接调用 WorkspaceSurface，日志页作为 WorkspaceContent 中的常驻内容接入，不再反向承载工作台。未改变已有模块状态、截图协调器或各功能持有的业务控制器。


窄屏导航抽屉状态与手势归 Index／WorkspaceSidebarState。沿用原版边缘区域、水平意图判断、revealPanel 和关闭动画；当前视图解绑同时取消手势并使待执行帧失效，避免旧实例请求新界面焦点。日志页通过绑定命令开闭抽屉，报告大纲互斥状态，导航／搜索构建器和宿主入口均由应用层持有。


统计、收藏、问答引用和随记来源的跳转由 Index 决定，WorkspaceSurface 直接调用已绑定工作台命令；LogsReaderPage 仅接收日志来源目标并负责日期加载、小节定位。目标沿用公开版的原始标题、标题序号和收藏解析标识；模块过渡、草稿确认及绑定有效性仍由应用层统一守护。此处不修改读取接口、链接协议、页面布局或业务写入。


桌面搜索的输入、候选列表、历史选择及键盘处理由 DesktopWorkspaceTopBar 承载，继续复用 WorkspaceSearchController。Index 决定搜索结果的模块切换、同日定位与跨日草稿确认，并拒绝解绑后的选择和确认回调。日志功能接收携带关键词的 LogSourceTarget，复用既有日期加载与高亮协议；窄屏搜索浮层由 WorkspaceSurface 装配，和桌面搜索共用 Index 的结果跳转入口。


紧凑顶栏和应用设置面板由 CompactWorkspaceTopBar 承载，保持原 AppTopBar、bindSheet、主题按钮及关闭后执行操作的交互。开启状态归 Index，WorkspaceSurface 构建宽／窄顶栏并通过当前视图绑定的命令调用应用操作。Index 直接传递应用层装配参数。


工作台的宽屏导航、筛选浮层、重置筛选和窄屏抽屉由 WorkspaceSurface 直接装配；日志日期列表由 WorkspaceLogNavigation 构建，日志功能通过当前视图回调提供读取和新建操作。Index 持有 NavigationRefreshController，刷新返回时检查当前视图绑定、实例、模块、日期和列表快照；导航刷新不重新打开文档或改变编辑器。保留收藏写入与问答历史加载期间的并发保护。


Index 持有顶栏菜单、主题、紧凑设置、导航浮层、区域高度及搜索焦点状态；应用操作拒绝旧绑定调用，延迟焦点也核对视图身份。设置／关于的 ToolbarAction 通过 focusKey 将焦点请求定向到内部原生 Button，外层控件 ID 仅作识别；保持原布局与样式。


桌面设置／关于菜单由 DesktopWorkspaceTopBar 构建并调用应用操作，WorkspaceSurface 不再接收日志页提供的应用菜单构建器；Index 通过当前日志视图的 closeLogMenu 回调关闭日志菜单。


共享收藏首次读取与实例搜索历史恢复由 Index.connectedTo 启动，前提是实例代次检查及草稿加载已经完成、模块控制器已经重建且工作台已连接。Index.invalidateModules 统一清理搜索、日期导航和收藏请求；LogsReaderPage 的挂载／卸载仅管理日志功能生命周期，不再决定共享控制器的初始化与销毁。日志大纲打开时按需刷新收藏仍保留。

冷启动覆盖层直接复用个人版 LaunchIntro 和浅深色资源。无可恢复连接时，LoginPage 完成初始化后允许覆盖层退场；自动恢复连接时，Index 等待首个日志内容就绪或失败回调，组件自身保留原版的超时退场。覆盖层只在当前应用进程首次展示。


WorkspaceLogNavigation 持有日志导航及日期弹层构建器，WorkspaceSurface 在宽屏和窄屏抽屉中直接装配；Index 持有其展开／查询／日历展示状态及滚动器，并在工作台重置时清空。日志页只报告当前日期，提供日块读取、未保存确认、新建和小节定位回调，不再提供应用导航视图构建器。工作台宿主由 Index 持有，日志弹层回归日志模块自身的挂载机制。


Index 创建每个实例的 LogSession，并通过 ObjectLink 交给日志功能；应用层仅读取它的日期／标题用于导航展示，日志文档与编辑器控制器仍管理日块事务。实例重置时更换该状态。日志加载提示由日志页通过 Link 发布到工作台根层。WorkspaceNavigationView 只注册功能动作，不传递视图构建器；注册的工作台命令通过 Link 更新到 Surface，避免常驻日志晚于外壳挂载时保留空命令对象。

阅读目录和 AI 标注审阅挂在日志内容内，内部链接沿用原版原生 Sheet 参数并挂在 SourceEditor 上，收藏分组 bindContentCover 独立挂在日志根节点；两个弹层不共用同一挂载节点。内部链接关闭后等待 Sheet 的 onDisappear 再释放编辑器选区并恢复焦点；退出日志生命周期时立即释放且不请求焦点，迟到释放也不能影响新页面。

随记更新的未知结果核对同时受控制器 lifetime 与编辑会话 revision 保护；删除核对受 lifetime 保护。异步读回无论成功还是失败，发布原写入错误前都必须再次校验，避免旧请求覆盖新会话状态。

候选随记提取按组件 lifecycle 和当前实例 revision 检查异步返回；旧上传结束后不再发起下一份解析或模型请求，旧保存完成不再触发新页面回调。仍在服务端执行的请求不等于被取消；这里只隔离后续调用和页面反馈。

材料缓存由 cacheImportUri 负责复制和校验，失败时清理本次目标文件；候选选择器整批失败时释放本批已经成功缓存的文件，原有材料仍归页面生命周期管理。两层分别负责单文件失败和批次未接管的缓存，不改变原文件。

普通随记新建与 AI 候选的默认记录时间共用 NoteTime，按北京时间生成带 +08:00 的分钟精度字符串。原生日期／时间选择器使用北京时间的显示字段，不能把设备本地时刻直接标记为 +08:00。服务端以自身时钟校验记录时间，允许最多 10 分钟的设备时钟偏差，超过容差的未来记录仍被拒绝；客户端不静默改写用户所选时间。

随记更新收到版本冲突时，NotesController 保留正在编辑的本地草稿，同时用已取得的服务端列表替换过期列表和筛选计数；读取代次使更早发起的列表请求不能再覆盖该快照。用户明确放弃草稿后重新打开，看到的是服务端版本。


普通工作台按键由 Index.handleWorkspaceKey 直接分派 F6、全局搜索、非日志模块回顶、随记保存信号、新建问答和应用弹层 Escape；workspaceShortcutBlocked 汇总应用层状态与日志功能报告的忙碌条件。日志页仅提供本地菜单／大纲关闭和日志保存、查找、回顶、前后日等命令，普通非日志快捷键不再依赖日志页分派。Escape 保留原有应用主题／菜单、日志菜单、日历／历史浮层、大纲、搜索、抽屉及阅读模式的处理顺序；新建和日期跳转继续经过离开确认，迟到回调核对当前绑定。主题面板在首帧完成后聚焦原生关闭按钮，使触摸打开后的按键进入应用事件链；卸载或再次发起焦点请求使旧帧失效，不增加可见布局节点。

鸿蒙 `EntryAbility` 负责启动窗口的主题颜色：读取本机偏好后、以及系统／应用明暗配置变化时，按既有浅／深 `start_window_background` 资源的颜色更新同一 UIAbility 的下一次启动窗口。该 API 不参与日志页或工作台的正文绘制；尚未运行过的首次安装启动仍使用 `module.json5` 的静态资源，调用失败也由静态资源兜底。

登录页窄屏 Scroll 使用 LayoutPolicy.matchParent 与 ignoreLayoutSafeArea(SYSTEM, TOP) 延伸实际布局视口；Scroll 内部内容单独通过 TYPE_SYSTEM.topRect.height（px 转 vp）保持初始顶部避让。登录页监听系统避让变化并在离开时注销，异步窗口获取检查页面代次，不阻断公开实例恢复流程。宽屏布局、纹理、字体、密码保护及根页面 RESIZE 保持原职责；布局坐标、UiTest 命中边界与实际绘制必须分别验收。
