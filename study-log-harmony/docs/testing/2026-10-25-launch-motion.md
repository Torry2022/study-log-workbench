# 启动动效与本机更新（2026-10-25）

维护者确认 Windows 水滴方案后，同步至个人版和通用版鸿蒙。保留现有启动页布局、文案和四层 SVG；每处碰撞产生一大一小两滴，只使用 Logo 两色。细颈约 120ms 拉长后收细断开，水滴收圆并连续缩小、淡去。

鸿蒙由单次原生 Animator 时间线同时更新 SVG 位移与水滴 Canvas，按当帧圆点和线端的距离触发接触。汇聚后的回弹幅度按 Logo 尺寸约束，避免手机长屏和宽屏因纵横行程不同而碰不到；初始画外行程仍按屏幕计算。原有就绪和退出流程保留，页面离开时取消定时器、解除 Animator 回调并结束动画。
