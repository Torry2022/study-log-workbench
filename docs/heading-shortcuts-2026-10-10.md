# 补齐正文标题快捷键

源码编辑原先只绑定了三级标题。现增加 `Ctrl + Alt + 4`、`Ctrl + Alt + 5`、`Ctrl + Alt + 6`，与既有 `Ctrl + Alt + 3` 分别设置三级至六级标题；沿用原有标题命令，替换当前行的标题前缀并保留正文，也支持选中行及空行。Mac 绑定继续使用对应的 Mod + Alt。

使用帮助逐项列出四个快捷键，避免一个过长的按键标签挤压说明。编辑菜单原已支持三级至六级标题，保持原操作与样式；没有新增一级或二级标题入口，日志的日期标题及正文限制不变。Windows 内嵌网页和普通网页共用 `LogEditor`，没有桌面专用快捷键分支。
