# MCP 调用时限

2026-11-03，本地修复，未发布。

调用函数已有timeoutMs参数及从连接前开始的总计时器，但工具请求内部另设45秒上限。现在工具请求服从传入时限，默认仍60秒；连接仍最多15秒，且计入同一总截止。取消、来源校验及错误处理保留，没有新增重试或后台索引任务。

两版使用相同调用约定。个人版Pi可在自己的既有总任务期限内传入动态剩余研究时间；通用版调用默认值保持。

真实SDK协议的离线检查覆盖旧45秒之后仍可完成、预算到期退出和长预算下即时取消。大型冷索引仍可能超过普通调用60秒上限，这次没有解决所有调用方的冷启动可用性；发行前需另行核实索引准备和服务就绪。
