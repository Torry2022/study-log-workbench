# 日志问答

问答只引用当前实例的日志原文。`logs_only` 限于日志证据；`logs_and_general` 把通用知识补充与日志依据分开。随记与 Wiki 不参与检索。

检索规则保留日期范围、时间线总结、对比与原文定位；无效日期不得自动滚到下月。原文定位保留用户输入的全角字符。引用按回答首次出现顺序编号，代码、链接及 HTML 中的引用样式文本保持原样；缺少引用时给出来源提示。

目前检索规划与回答规范化的 23 项合成测试通过。它们只证明纯逻辑边界，流式接口、真实模型和整个问答工作区尚待验收。

## 历史存储

会话保存在实例的 `state/rag-sessions.json`，写前完整快照存入 `BACKUP_ROOT/rag-sessions/`。读取遇到损坏 JSON 或结构异常会报错，不会当作空历史覆盖。写入经过单进程串行队列、独占临时文件、同步落盘与原子替换；实例服务锁限制同一数据目录的 Web 写进程。

每个会话有独立版本。创建使用客户端稳定 UUID，修改携带版本和操作 UUID；响应丢失可用原请求重试，冲突保留客户端内容。删除留下最小操作凭据，迟到的创建不能复活已删除会话。停止和失败回答保留实际状态，未结束的流不能入库。自动标题在调用模型前检查是否仍为默认标题，完成后再次核对版本；手动标题优先。

17 项临时实例存储测试通过，包括并发冲突、幂等重试、删除防复活、损坏文件保护、写入失败、备份及 Windows 目录联接边界。HTTP 接口和浏览器生命周期仍待验收。
