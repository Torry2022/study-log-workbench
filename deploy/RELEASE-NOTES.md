# 学习日志工作台 0.1.0

这是 Windows x64 与 Linux amd64 自部署服务器的首个正式版本。rc.9 及更早的预发布仍保留，可直接升级并继续使用原有记录和配置。

## 本次更新

- 网页与 Windows 统一工作区动效和加载反馈。切换模块、日期、日志详情及浏览／源码／分屏时保持内容稳定，WebKit 和快速连续切换具有后备处理，减少动效设置继续生效。
- 收藏、随记和统计在后台刷新时保留已有结果；首次无内容时延迟显示加载状态，统计月份切换和刷新使用工具栏加载线，本地筛选、排序和分页只做结果淡入。
- 分段控件使用移动选中底色；Toast、弹窗、图片预览、展开区、历史版本和重点标注窗口补齐协调动效及最大化／还原。
- 日志月份、日期与正文读取减少重复解析并复用内容缓存；慢请求、失败重试和快速切换不会用旧响应覆盖新选择，也不丢弃编辑草稿。
- 问答支持在切换会话或模块后继续后台生成，历史会话显示运行状态；长范围问题采用有界证据读取和来源校验，明确日期、跨月范围及追问来源得到保留。
- 检索复用解析结果和 BM25 统计，支持可选向量检索；Agent 路径按模型能力启用，不绑定单一模型，普通 RAG 继续可用。
- 统一应用 Logo、右侧工具栏、滚动区域和标题栏细节，并保留现有阅读、编辑、备份和恢复流程。

## 安装与部署

Windows 下载 `study-log-desktop-0.1.0-x64-setup.exe`。安装前保存内容并正常退出应用，选择原安装目录覆盖安装；已有学习记录、配置和历史版本保留。

服务器附件为 `study-log-server-0.1.0.zip`；web、mcp、tools 使用同版本配套镜像。升级前先创建完整备份，再将 `RELEASE_VERSION` 改为 `0.1.0` 并拉取三个镜像。桌面更新不会更新服务器，也不会同步本地与服务器的记录。
