# Windows 本机使用

此包在默认浏览器中运行现有工作台，包含固定版本的 Windows x64 Node、网页服务和本机关键词检索。使用时无需安装 Node、Docker 或执行源码构建。学习记录、索引与备份留在本机；模型功能仅在配置后连接指定接口。

## 从第一篇记录开始

1. 将包完整解压到程序目录，例如 `D:\Apps\StudyLogWorkbench`，不要直接在压缩包内运行。
2. 双击 `启动学习日志.vbs`，浏览器打开本地启动页。首次运行选择新的专用保存文件夹，例如 `D:\StudyLogData`；不能选择程序目录或其父目录。目录须为空或尚不存在。
3. 设置至少 12 个字符的访问密码，点击“新建实例”。已有有效实例用“打开已有实例”，不重新初始化学习记录或密码。
4. 点击“启动工作台”，在打开的工作台中用刚设置的密码登录。无需配置模型即可新建今天的日志、写几句话、保存并搜索。
5. 使用结束后回到启动页，点击“停止工作台”，等待按钮恢复为“启动工作台”后关闭页面。仅关闭工作台浏览器标签不会停止后台服务。下次启动仍可打开上次选择的保存位置。

源码与学习记录分离，更新程序时保留整个实例目录。不要将实例目录、环境文件、归档或含个人内容的截图提交到 Git。

如果电脑策略禁用了 Windows Script Host，当前包不能双击 VBS 启动；可使用随包运行时执行 `runtime\node.exe ops\desktop\launcher.mjs`。不要为了运行而改系统安全策略。首版仅 Windows x64；没有安装服务、开机自启或系统托盘。

## 编辑和 AI

日志源码模式和随记的“编辑”菜单提供常用 Markdown 操作，单次操作可撤销，不自动保存。日期由系统维护；三级标题是主要小节，四至六级用于内部层次。

模型配置是可选项。先停止工作台，在启动页展开“模型配置”，填写完整接口地址、模型名和 Key，保存后重新启动。空 Key 保留已有值，清除须勾选“清除已存密钥”。启动页不读回密钥。只有聊天模型也能使用带来源的日志问答，无需向量或重排服务。

日志 AI 面板提供三套技术学习预设及个人方案，详见 [AI 配置](ai-configuration.md)。导入材料会按请求发送给配置的模型服务；结果需审阅、修改并显式保存，不把教材内容写成已完成的个人实践。

## 备份和恢复

启动页的“备份与恢复”复用 [整实例归档](backup-restore.md)：

1. 点击“保存新备份”，选择实例目录之外的新 `.slwb` 文件。入口会先停止服务、等待在途请求，再备份与核验。完成后服务保持停止，可再次启动。
2. 归档及同名 `.sha256` 摘要一起保存；可使用“校验备份”检查完整性。备份包含密码与模型凭据，不是公开分享文件，也未加密。
3. 恢复填写尚不存在的新目录，例如 `D:\StudyLogRestored`。恢复不覆盖旧实例；成功后入口选中新实例，密码与学习记录保持原样。

正常停止先结束 Web，再停止检索服务，最后释放实例锁。异常结束会保留明确提示与锁；不会凭 PID 或经过多久就自行清锁。遇到“运行异常”时先确认进程与文件状态，按 [维护说明](maintenance.md) 排查，不反复删锁启动。

## 网络与权限边界

服务仅监听 `127.0.0.1`，自动选择空闲端口；入口用当前 Windows 用户的私有控制信息协调服务。新建的实例目录和包含凭据的新文件只授予当前用户权限。程序不修改防火墙、系统代理或其他服务。程序目录应放在可信位置，不供其他用户修改运行文件。

鸿蒙仍连接显式配置的服务器。此包仅本机监听，因此手机／平板不会因电脑启动本地包而自动连通。需要多设备访问时使用现有 [Docker／源码自部署](deployment.md)，本轮没有新增网络暴露向导。

## 维护者打包

在 Windows x64 的公开仓先安装锁定依赖、完成网页生产构建，再执行：

```powershell
npm run package:windows -- "D:\Builds\StudyLogWorkbench-win-x64"
```

输出目录及同名 ZIP 必须不存在。打包器从 Node 官方下载固定 22.23.3 运行时并核验归档和可执行文件摘要，随包保留许可证及 `package-manifest.json`。源码仓不跟踪运行时、依赖、ZIP 或构建产物。打包完成不代表已经公开发布。

本轮实际结果和未覆盖条件见 [产品实施记录](product-iteration-acceptance.md)。

维护者反复提供本地候选时，可用 `node ops/desktop/trial-entry.mjs "D:\Trials\Current" "D:\Builds\StudyLogWorkbench-win-x64"` 在独立目录创建固定的“启动学习日志.vbs”。后续只更新该入口的目标，保留旧包及学习记录；它不会停止服务、迁移学习记录或自动启动工作台。切换包之前须从旧启动页正常停止工作台，新入口中打开原有学习记录目录，不能重新初始化。

启动页会检查所选目录：空目录显示新建与密码输入，已有有效实例显示打开操作，其他非空目录或存在待检查锁的目录显示原因。保存位置就绪后才能启动；运行时提供打开与停止操作，并锁定目录及模型配置。启动／停止共用一个按钮：实例未就绪时禁用，启动完成后切换为“停止工作台”，正常停止后恢复。没有单独的退出按钮；停止服务后可再次启动，也可关闭页面。未运行时关闭最后一个启动页标签，管理入口会在短暂等待后自动退出；刷新页面或其他打开的启动页会保留入口。运行中关闭页面不会中断服务，可再次双击同一启动文件回到管理页停止。
