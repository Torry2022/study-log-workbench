# 0.1.4 发布记录

0.1.4 整理了问答的回答版本与操作，改善生成过程中的正文展示和阅读位置，并同步鸿蒙边栏及问答布局。产品版本为0.1.4，鸿蒙构建号10400。此前版本保留，正式附件与镜像以v0.1.4发布页面为准。

## 本次变化

同一个问题的不同回答可以用回答底部的左右箭头切换，来源、复制和重新生成也放在对应回答下方。生成中的正文陆续显示；用户上翻后暂停跟随，回到底部再继续。切到其他模块只断开观看，后台任务仍会执行，重新打开时直接显示已收到的内容。

保存和复制始终使用完整文本，不等待展示队列。网页任务观看使用原生SSE，修正已复现的WebKit大快照接收停顿，保留完整旧回答和实例隔离；首段正文立即保存，后续仍批量写入。问答检索、模型及Agent能力开关沿用既有实现。

阅读与编辑保留保存前的位置，改善浏览切换、退出阅读模式及大纲跳转的衔接。鸿蒙同步回答操作、示例问题、抽屉与边栏层级，减少输入区多余留白，并修正换行符差异导致的未保存提示。

## 验证与安装

Web测试631项通过、3项既有跳过；MCP60/1；运维51/1；desktop及Electron单测27项；鸿蒙协议316项、编辑器6项。类型检查、Web生产构建、Windows安装器、Linux amd64三镜像及鸿蒙release构建通过，全部使用隔离合成资料和本机模型替身。

问答实现11b87bf已通过统筹独验，包括99项相关测试、44项跟随与切换、30项平滑、16项实例边界及原任务、结果、输入区和版本回归。新版补充Ch／Wk浅深色、三种视口和上下滚动的布局检查，修后再次通过44项跟随和30项平滑。容器部署6组、问答3组、任务归档恢复11组通过；任务专项由统筹独立复跑。

Windows已在原目录覆盖，安装器正常退出；统筹逐一核对5259份安装文件，原资料与配置20份文件哈希不变。已安装EXE与随包Node的独立任务11组通过，包括远程关窗继续、本地退出中断、重新生成和重开不重放。已安装EXE另通过浅深色、短长会话与三种窗口尺寸的4组／48个侧栏几何样本。开发方的隔离运行与真实安装分别记账，不以解包代替安装。

鸿蒙未签名HAP已重新构建。统筹与已验6d9e7d7候选逐项比对，202个条目中200个逐字节一致，仅module.json和pack.info的四个版本字段变化；沿用该候选列明的实机证据，没有把新版HAP记作已安装。其他使用者独立签名及外部HTTPS仍未验。
