## 验证

- 鸿蒙 `node --experimental-strip-types --test test/*.test.mjs`：241 项通过。
- 编辑器运行时同命令：4 项通过；重新生成已跟踪的 rawfile 编辑器资源。
- Playwright 加载实际 rawfile 编辑器，在 Chromium 实际按 H3—H6快捷键、再次按键和撤销：12项检查通过。
- 本地 `assembleHap` 成功，包含 ArkTS 编译；存在工程既有 API 弃用和兼容性警告。
- 本轮未在平板模拟器操作原生页面，新增引导的宽窄布局与键盘弹出后效果仍需设备检查。当前 HDC 目标未确认为已授权模拟器，未向这些设备安装。

## 尚需单独核对

- `LogDayBody` 仍用正则移除尾部分隔线。常规服务端已处理日块边界，但历史恢复内容与未闭合代码块的组合需通过实际响应进一步核对；本轮没有改变存储协议或历史内容处理。
- 大纲复杂嵌套（如引用、列表内标题）与 Web 渲染标题的全面一致性仍需专门检查；本轮测试覆盖普通标题、缩进代码和匹配代码围栏。

没有修改个人版、线上资料或日常安装，也没有发布本轮构建。网页的 CSS、Windows 菜单与窗口修正不直接复制到 ArkUI。
