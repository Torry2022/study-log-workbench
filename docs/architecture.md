# 架构

`study-log-web/app` 使用 Next.js App Router 提供 `/study-log` 入口。根布局在首次绘制前初始化主题；基础CSS注册三个本地字体族，原始字体与许可证作为静态资源提供。

认证API使用实例密码校验和HMAC签名；Cookie与App Token按受众区分。能力接口只读取实例身份，不产生资料写入。日志业务、AI和检索尚未接入。

`AuthGate`负责认证生命周期，`LoginScreen`仅持有密码、提交中和错误状态。认证过期保留工作区组件实例并隐藏内容；重新认证后恢复，主动退出则卸载清理。共享JSON请求在会话变化时取消，并在解析响应后检查取消状态，避免不遵守取消的旧响应回灌。后续业务模块从会话上下文读取活动状态，并分别验证草稿与流的生命周期。

`ops/instance.mjs` 负责实例初始化。它只操作显式传入的绝对目录，识别已有身份，使用独占创建保留原配置。`ops/run-web.mjs`读取选定实例环境，强制数据根为该实例的data目录，持有运行锁直到服务退出。锁冲突拒绝操作；完整停机和恢复场景将在维护批次验证。

## 数据边界

源码仓仅保存代码、公开资源与合成测试；用户资料和配置属于显式指定的实例目录；索引是可重建数据，备份是独立恢复资料。后续实现不得依赖源码父目录寻找资料。
