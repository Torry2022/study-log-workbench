## 实现与边界

| 环节 | 当前行为 |
| --- | --- |
| 查询条件 | 字面条件与日期同时保留；无字面命中时不再悄悄退回语义检索。单独列举的日期、月份分别查询，连续月份范围包含中间月份。支持“九月和十月”、省略第二个年份。 |
| 事件日期 | 对“2026年9月15日发布”等明确事件表达移除日志日期过滤；原始问题仍交给回答模型。这里是规则识别，不声称覆盖所有自然语言歧义。 |
| 范围读取 | 月份总结、跨月比较通过 `read_log_range` 读取原始日块。返回总日数、已完整读取日期、版本游标；源内容变化使后续游标失效，不把两版分页拼成完整材料。 |
| 证据 | 请求内保存文件、日期、原文位置、哈希、摘录与读取状态；重复身份合并，编号统一。搜索命中不代表全库穷尽；空范围、读取失败、部分结果与完整范围分别记录。 |
| 材料较长 | 仅在最终模型输入容量不足时分批选择逐字原文摘录，保留来源身份；失败时标明材料限制，不把失败批次当作完整材料。 |
| 引用兼容 | 最多保留 160 个来源、240000 字符原文。生成后发送实际使用的来源；流解析、会话保存及追问指针统一采用 160 条上限，超出时明确报错，不静默删引用。 |
| Agent | 明确的简单问题继续直接检索。实验路径允许换词搜索及读取已命中日期，最多 2 轮 SDK 工具执行、累计 8 次 MCP 读取，整轮 120 秒。重复查询、无新增证据、失败或上限会停止；内部文本、推理和工具消息不进入聊天历史。 |
| 供应商 | 适配器请求用户原有完整 URL，包含路径和查询参数；不重定向、不自动重试。未知工具能力默认走普通 RAG；401、429、网络失败作为错误处理，不假称“不支持工具”。工具 JSON Schema 另有运行时校验；关闭 SDK 默认错误正文日志。 |
| Jev | 固定 `jev-1.13.0`，只判断证据支持与前提冲突；校验选择项和概率，不让置信度授权工具。8 秒超时、零重试、禁用正文日志，与整轮共享取消。未配置或失败不阻断正常问答。 |
| 追问 | Web 可在历史消息中附带 `sourceRefs`。服务端验证文件归属、日期、哈希格式及编号完整性，重新读取当前原文；不会把历史哈希当成内容仍未改变的证明。旧客户端不传仍可问答。 |
| 会话标题 | 首次回答保存后异步生成标题，不挡住下一次模型请求。后续保存仅合并已知的标题版本变化；其他并发修改仍走原有冲突保护和同一保存快照重试。标题模型限时 10 秒。 |

覆盖信息进入最终提示词，要求答案交代读取缺口；代码保证范围和状态真实，但不能保证模型每次都遵从。达到步数、字符或时间上限不代表任务已经完整完成。查询范围很大时仍可能需要用户缩小范围。

## 配置实验路径

确认当前模型和接口支持工具调用后，在 Web 服务使用的环境配置中同时设置以下两项；这项要求适用于所有供应商和模型：

```dotenv
RAG_AGENT_ENABLED=true
RAG_AGENT_TOOL_CALLING_VERIFIED=true
```

两项缺任一项均使用普通 RAG。更换模型或接口后应重新检查工具能力，不沿用旧的确认。模型 URL/key/model 继续使用已有聊天与轻量模型配置。Jev 还需 `RAG_JEV_ENABLED=true` 和私有的 `TYPESAFE_API_KEY`；默认关闭，密钥不得写入提交或共享报告。

Windows 和服务器使用相同 Web/MCP 实现。服务器需同时更新 Web 与 MCP 才有 `read_log_range`；旧 MCP 缺少工具时明确报读取失败，不把 top-K 搜索包装成完整月份。鸿蒙继续使用已有 SSE 协议；本轮未新增原生界面或设备安装。

## 真实模型小样本

使用 `scripts/rag-model-acceptance.mjs` 创建全新合成资料。材料含技术概念、读取接口排错、普通读书笔记及否定/条件；两条路径同用官方 `deepseek-flash` 最终回答模型与本机关键词检索，不读取真实日志。每道问题每条路径只做一次，无自动重跑。

| 问题 | 普通 RAG 调用数 / 用时 | Agent 调用数 / 用时 | 人工核对 |
| --- | --- | --- | --- |
| 九月与十月比较 | 1 / 13.7 秒 | 2 / 19.4 秒 | 两边均读取全部 5 个合成日块，引用覆盖两个月；未见 Agent 增益。 |
| 读取接口不能任意重试 | 1 / 1.7 秒 | 3 / 9.1 秒 | 两边保留鉴权例外；Agent 出现“只有只读请求”这种比材料更强的限制，不满足不退化标准。 |
| 回忆流畅与理解正确 | 1 / 2.4 秒 | 2 / 5.0 秒 | 均承认材料未解释机制，未用外部知识编造原因。 |
| 不存在的水稻实验 | 1 / 2.3 秒 | 3 / 7.0 秒 | 均未编造实验原因。普通路径多解释了无关来源；Agent 开头有“知识库中没有”的过强措辞，后文才说明未穷尽。 |

这 8 次问答、14 次模型请求不能证明可重复的质量收益。Agent 因此继续关闭，后续需改善证据不足时的回答措辞，并扩大固定样本后再评估。Jev 只有官方 SDK 替身协议测试，缺少凭据，不能把它标成三路真实质量比较已完成。
