# 并发工具的新增来源归属

同一步并发执行两次搜索时，原先从调用前后的共享来源数量推断新增证据。较晚返回的空搜索因此可能把另一搜索新增的来源算到自己名下，并继续模型循环。

证据收集现在在每次同步登记原文时记录本次新增的来源编号，并将这些编号返回调用方。搜索和读取只报告自己新增的来源，停止判断使用同一结果；原有来源编号、去重、覆盖、预算和终止状态保持。没有增加工具或模型步骤。

实际 SDK/MCP 合成专项通过延迟空搜索复现缺陷：修复前错误进入第二次决策，修复后按无新增证据结束。另以并发收集核对命中返回自己的来源编号、空结果返回空数组，共享证据保留唯一来源。

类型检查、生产构建及部署候选 Node 22.23.3 串行 169 项 RAG 回归通过。正式生产接口与 Chromium/WebKit 浅深色九项检查通过，截图已查看；报告在 `.local/rag-entry-production-1791789530762/`。本次验证为模型替身及合成资料，没有新增付费调用或提交实际资料。
