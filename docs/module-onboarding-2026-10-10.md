# 各模块起步引导

## 行为

现有新工作台日志示例保留。其余模块使用共享 Web 界面引导，Windows 内嵌网页复用相同代码，不增设教学模式、首次使用标记或配置项。

- 随记：没有随记时展示一个独立观点的写法示例，保留适用条件，明确“不会保存为随记”。说明随记与按天记录的日志有什么区别；“新建随记”打开原有空白编辑器，用户填写并保存后才写入。取消不创建记录。有随记但筛选无结果时只显示筛选提示。
- 收藏：没有收藏时说明已保存日志中三级标题旁的星标及分组用途，提供“前往日志”。不替用户收藏示例，不创建默认分组。有收藏但筛选无结果时不显示首次操作引导。
- 问答：有日志且当前问答为空时显示三个示例问题；点击只填入原问题输入框并聚焦，回答范围保持原选择，仍需明确发送。已输入问题时隐藏示例，避免覆盖草稿。没有日志时引导前往日志；缺模型或检索配置时继续使用现有配置说明和发送拦截。不会创建假回答或历史，不自动调用模型。
- 统计：解释记录天数、小节计数和数量不代表掌握程度，提醒普通示例日志也参与统计；没有日志时提供返回日志的入口。不生成示例统计、预设领域或映射。

这是界面展示与现有操作衔接，不改变初始化、存储、业务接口及问答协议。已有工作台也可按内容状态看到引导，不向已有学习记录补写示例。本批没有修改鸿蒙原生界面。
