# 日志大纲定位修正

大纲使用当前编辑正文，但原点击路径经过日期导航，并用已保存的正文检查小节。已保存的短记录新增 H3／H4 后切换浏览、点击大纲，会误报目标不存在；草稿并未丢失。独立 Playwright 在修正前复现失败。

大纲点击改为在当前预览中定位对应标题，不重新读取日志、不保存、不触发跨日期导航。日期、收藏及内部链接仍检查保存的来源；真实失效的目标仍提示。窄屏定位计入实际可见的日志工具栏，标题不能滚到工具栏后方。正文网格的隐式行按内容高度排布，提示不再分摊剩余高度；分屏已有显式行规则保留。

收藏继续以 H3 为单位；H4–H6 是小节内部层次。草稿未保存时不可收藏。左侧标签来自保存的摘要，新增标题保存后更新；未保存时显示原摘要不表示正文丢失。

验证：`ops/browser-log-outline.mjs` 使用隔离合成目录，检查未保存 H3／H4 反复定位、保存后摘要更新、收藏层级、真实失效提示高度及宽窄屏实际滚动位置。无模型调用，不操作日常记录。当前仅源码修正，不代表已替换安装包。

实际结果：类型检查、生产构建及独立 Playwright 通过。1230×820 与 390×820 的 H4 均定位到可见工具栏下方；真实失效提示高 56px，与正文容器间隙为 0。截图已检查，证据在本机 `.local/log-outline-1791467524127/report.json` 及同目录图片。
