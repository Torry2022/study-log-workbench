# 日志正文三击切换核对（2026-10-09）

## 来源与取舍

个人版 StudyLogApp 的 handlePreviewClick 只处理浏览模式的三击，排除链接、按钮、输入、图片、代码和 Mermaid；调用原模式切换并聚焦编辑器，延续阅读位置，并不把光标精确放到点击的字符。

公开版已经具备 changeMode、useReadingPosition 和编辑器自动聚焦，缺的是手势入口。因此在共享 LogReader 接入同一行为，保留显式模式按钮，不复制个人版大型组件，也不添加 Windows 注入逻辑。此手势替代普通正文的鼠标三击选段；单击、双击选词及拖动选择机制不改，触屏点击不触发切换。使用帮助同时说明鼠标三击入口。

## 边界

- 仅当前已加载且可编辑的日志浏览区生效；源码及分屏不变。正文可以是已有日志的草稿，也可以是新日期尚未首次保存的草稿。
- 阅读模式下先捕获现有阅读位置，再退出阅读模式并显示源码；沿用原有位置恢复和编辑器焦点机制。
- 不保存、不丢弃、不重新读取正文。已有保存、冲突和离开确认流程不变。
- 链接、图片、代码、表单控件及 Mermaid 排除；处理放在日志容器，不改 MarkdownPreview，所以问答答案、随记预览等不会获得编辑手势。

## 验证

- Web 类型检查、生产构建及独立脚本语法检查通过，构建日志 `.local/triple-click-build.log`。
- `ops/electron/preview-edit-smoke.mjs` 使用隔离临时配置、45 节合成长日志；Electron 1440×864 和普通 Chromium 1440×900 的最终证据为 `.local/preview-edit-1791542817043/report.json`。
- 实际鼠标单击／双击保留浏览与文本选择；三击普通标题切源码并聚焦，长日志滚动不归零，返回浏览后原目标仍在视口；内部链接、行内代码与代码块的三击不切模式。触屏排除使用 PointerEvent 替身验证，未冒称真机触摸测试。
- 阅读模式三击退出阅读并进入源码；已存在日期的未保存草稿及新日期首次保存前的正文均保留。请求计数确认手势不发送 PUT；随后显式 Ctrl+S 保存成功。分屏三击不改模式。Chromium 420px 窄屏外接鼠标行为和编辑焦点通过。
- 人工核看最终 Electron 长日志源码截图与首轮窄屏源码截图。图片、表单和 Mermaid 排除由源码条件核对，本批未逐项做实际点击回归；未改共享渲染器，不将本批结果外推为问答或全部 Markdown 验收。
- 首轮已通过已保存日期流程；复核个人版就绪条件后发现它不要求已有磁盘记录，故将公开版手势条件由“已保存日志”修正为“当前编辑文档已就绪且无加载错误”，补充首次保存前的检查并重跑通过。
