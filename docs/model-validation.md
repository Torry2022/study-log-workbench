# 真实模型小样本验收

2026-09-22 使用独立空实例与合成队列材料，通过真实 Web HTTP 路由及本机 MCP 完成 5 次 `deepseek-flash` 请求。应用没有内置此模型；它只是本次明确配置的验收提供方。

| 场景 | 核对结果 |
| --- | --- |
| 日志生成 | 生成待审阅 H3 片段，保留 FIFO、入队/出队位置及实验顺序，没有捏造性能数字 |
| 重点标注 | 新增 2 处粗体；移除新增标记后与输入逐字符一致，代码保持原样 |
| 随记候选 | 返回 1 条候选；依据是材料中的实际原句，没有虚构个人心得 |
| 仅依据日志问答 | 完整 `done`，FIFO 和实验结论均带指向实际日志小节的引用，并说明未记录性能基准/锁实现 |
| 日志加通用知识 | 完整 `done`，引用同一原始日志，应用场景单独置于“通用知识补充” |

请求共输入 1,727 token、输出 3,644 token（含提供方报告的推理 token）。所有生成、标注、提取和问答完成后，原日志逐字节不变，随记没有自动新增。输出已经人工检查。这是很小的协议与质量样本，不证明复杂或陌生材料上的全面质量；分类建议、语义规划、自动标题、embedding/rerank 的真实模型质量未在本组验证，它们的本地替身测试另列。

## 明确启用并控制预算

普通 `npm test` 不调用付费服务。单独运行 `node ops/model-acceptance.mjs --real-model` 之前，必须通过进程环境提供：

- `REAL_CHAT_API_KEY`、`REAL_CHAT_API_URL`、`REAL_CHAT_MODEL`：专用测试凭据与端点。
- `REAL_MODEL_REMAINING_CNY`：已扣除之前所有调用预留的剩余授权额度。
- `REAL_MODEL_LEDGER`：新的绝对路径，保存请求发出前的持久预留记录。
- `REAL_MODEL_REPORT`：新的绝对路径，保存结果和用量；不要放入 Git。
- `REAL_MODEL_PORT`：可选，本机 Web 端口，默认 3575；MCP 使用后一端口。

当前测试代理只审阅了 DeepSeek 官方 `/chat/completions` 端点和 `deepseek-flash`。它每次用输入 UTF-8 字节数加协议余量估计输入上界，并强制最多 8,192 输出 token；以每百万输入 5 元、输出 20 元保守预留，高于核验时的 [官方 Flash 价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)。价格变化后必须重新核对，不能直接挪作其他模型的预算器。

预留在付费请求前写入账本并同步落盘；失败和超时不退还预留，代理不自动重试，同时最多处理一个请求、最多 12 次。本组预留上界合计 0.960005 元，**不等于供应商实际扣费**。重复执行须读取既有账本、扣除已预留金额，再提供新的明确预算和文件名；不能改名后把预算重新算满。

真实 Key 只进入代理内存，不传入被测 Web/MCP 子进程、不写实例文件，也不打印。只有合成材料发送给提供方。脚本保留临时合成实例及结果供复核，不操作已有实例。
