# Windows 桌面端

Windows 桌面端可以在本机保存学习记录，也可以连接已经部署的服务器。安装包包含运行环境，首次打开时选择使用方式即可。

## 开始使用

### 在这台电脑使用

1. 选择一个专门用于学习记录的空目录，并设置访问密码。
2. 打开“日志”，选择“今天”开始记录。
3. 从“文件”菜单管理模型设置、完整备份、恢复和历史版本。

程序目录与记录目录分别保存。卸载和重新安装应用时，记录目录继续保留；重新打开后选择原目录即可继续使用。

### 连接服务器

1. 按[服务器部署指南](../../deploy/README.md)准备工作台地址和访问密码。
2. 在首次使用页选择连接服务器，填写浏览器中能够打开的工作台地址。
3. 连接成功后，网页与 Windows 会访问服务器上的同一份记录。

切换连接会先确认新工作台可用，再切换当前会话。本机记录与服务器记录分别保存。

## AI 设置

从“文件 → 模型设置…”配置聊天、向量和重排服务。日志记录、随记、收藏、搜索和统计可以独立使用；配置模型后会开放材料整理、重点标注、分类和问答等能力。

模型请求会把当前操作需要的材料发送到所配置的服务端点。保存前可以审阅和修改生成内容。

## 备份与恢复

“文件 → 创建完整备份…”会保存记录、附件、配置和模型密钥。将归档和校验文件存放在受保护的位置。

“文件 → 从备份恢复…”会恢复到一个新目录，原记录目录保持不变。恢复完成后，应用切换到新目录；确认内容完整后再决定如何保留旧目录。

日志页面的历史版本用于恢复单日内容；完整备份用于保存或搬迁整个工作台。

## 运行与异常恢复

本机服务默认监听 `127.0.0.1`。正常退出时，桌面端会停止本机服务并释放运行锁。

电脑重启或应用中断后，再次打开会核对进程归属、记录目录和未完成写入。页面出现恢复提示时，先结束仍在运行的旧进程并确认记录目录可访问，再按提示继续。

## 从源码构建

需要 Node.js 22.13 或更新版本。在仓库根目录执行：

```powershell
npm --prefix study-log-web ci
npm --prefix ops/electron ci
npm run build
npm run package:windows
npm run package:electron
```

便携包写入 `.local/windows-package`，Electron 安装包写入 `.local/electron-dist`。安装包签名由发布者在构建环境中配置。
