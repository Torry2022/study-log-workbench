# 产品方向实施记录

本轮实现依据 [产品方向](product-direction.md)。以下为合成实例、本地构建和代理审查结果，不代表外部使用者反馈。个人版仓库只读；未推送、发布或覆盖日常设备应用。

## 网页 Markdown 编辑

复用 CodeMirror，日志源码日期行及随记正文／个人理解使用同一命令实现。提供正文、H3–H6、加粗、斜体、代码、列表、引用、表格、公式、链接及已有附件入口；宽窄屏共用菜单。日期由系统维护，不新增旧 H1／Setext 内容禁令。

- 命令测试 11／11 通过。
- 网页全量测试 304 项：301 通过、3 项既有平台条件跳过、0 失败；独立类型检查与生产构建通过。
- `ops/browser-markdown-edit.mjs` 在隔离合成实例通过日志与两个随记字段、格式转换、单次撤销／重做、选区、保存、中文组合输入起始阶段及 390px 菜单检查；宽窄截图已目视核对。
- 实际操作发现并修复：初始 compositionstart 尚未进入 CodeMirror composing 状态，改为同时检查 compositionStarted；鼠标打开菜单后 Escape 关闭行为补齐。
- H1／Setext 与现有业务目录、收藏、统计的语义差异仍是独立兼容议题，本轮没有重做存储结构。

## 日志生成方案

三个内置只读预设、现有默认模板与个人方案管理已接入网页。旧客户端不传方案标识仍读 generation.md；管理写入使用版本快照和写前备份，不把方案写入源码仓。

- 方案专项 18／18 通过：认证、只读保护、409 冲突、实例隔离、写前备份失败不改原文件，以及真实生成路由选用方案／省略标识兼容。
- `ops/browser-generation-presets.mjs` 真实 API 流程通过新增、复制、编辑、改名、默认、删除、冲突保留输入与刷新后对照再保存；390px 深色及桌面浅色截图已核对。浏览器生成响应使用合成替身。
- 共享的全量 Web 测试、类型检查和生产构建通过，结果同上。
- 三个预设各一次真实模型调用均返回草稿，未改日志字节、随记或备份；日常／实践保留未完成事项，概念样本明确教材身份，没有虚构亲历。不过概念样本增加了未标注的补充术语及泛化的溢出解释，仍需审阅，不能宣称严格只转述材料。详见 [模型记录](model-validation.md)。

## Windows 本机包

本地入口使用默认浏览器、固定 Node 22.23.3、Web standalone 与关键词检索；程序和资料分离，首次显式选择资料目录并设置密码。模型可选、内部检索凭据按运行生成，不要求用户配置 MCP。仅监听本机，不改防火墙／代理。正常停止通过继承的私有 IPC 让服务自身收尾，异常锁不按 PID 或时间删除。

- 当前源码在随包 Node 下的桌面及归档专项 **22／22** 通过、无跳过：重复启动、端口占用、不可写目录、退出拒绝新增操作、异常退出保留锁，以及归档权限回调失败保护。
- 新界面候选从 ZIP 实际解压后通过四条流程：新资料目录／自设密码／无模型首篇记录与搜索；真实 Next／MCP 正常停止及重开读回；实际 Web → 本机关键词 MCP → 合成模型带来源问答，回答中停止仍等到 done；完整备份校验后恢复到新目录，登录、记录、个人生成方案及默认选择保留。
- 上述报告在忽略目录 `.local\windows-package-design-final-smoke\report.json`，使用真实服务、合成资料；问答模型是本地协议替身，不计真实模型质量。
- 独立 Playwright 验证启动页宽屏浅色／窄屏深色、建目录、中文配置、密钥不读回、保存后重载、取消不显示成功；截图已检查。启动页复用现有浅深 Logo、图标、本地字体及配色，状态文案说明实际操作。
- 实际操作发现并修复：检索服务重复断开 IPC 导致非零退出；Windows 目录 ACL 设置不应强制修改所有者。源码审查发现并修复：恢复／归档写入前设置私有权限、Web 退出失败后仍需收尾 MCP、退出接受后拒绝排队及新增操作。
- 最终包附带使用、配置、维护和恢复文档，不夹带实例、密钥或验收数据。具名最终 ZIP 与入口核对结果在下方记录。

## 仍需明确的边界

Windows 系统目录／保存选择器尚未人工点击确认；路径直接填写及取消协议已验，VBS 真正打开默认浏览器与服务流程有独立证据。鸿蒙本轮三个新增原生界面的设备目视仍未完成。以上是未执行检查，不改成通过。

“新使用者是否能顺利选择资料目录、是否理解个人生成方案与补充要求的区别”仍是体验假设。多 Agent 审查与维护者操作不等于真实使用者反馈；本轮没有外部使用者和长期使用数据。既有 H1／Setext 业务语义、跨版本恢复、鸿蒙独立签名／异网络 HTTPS 等边界保持原记录，不纳入本轮无限追加验收。
