# 日志正文标题规则

日期标题由系统维护。正文可以没有标题；需要分层时使用三级至六级标题（`###` 至 `######`），三级标题继续作为主要学习小节。不允许在正文中使用一级或二级标题。

Markdown 的两种标题写法遵循同一规则：`# 标题`、文字下方的 `===` 都是一级标题；`## 标题`、文字下方的 `---` 都是二级标题。下划线直接跟在文字后面时属于标题，前面有空行时才可能是分隔线，不自动替用户转换或删除。

校验针对正文根层级的标题；围栏代码、缩进代码、引用和列表中的示例不是日志结构，保持原文。月／年文件最外层原有年度标题也不属于正文，不受这次保存校验影响。

网页保存前与服务端写入使用同一 Markdown 解析规则。服务端在创建、覆盖和追加写入前拒绝不符合规则的正文，返回现有 400 错误；网页和鸿蒙沿用现有错误提示并保留编辑草稿，修正后可以再次保存。日期结构、收藏、统计和接口字段不变。

已有内容仍可读取，不自动改写旧日志。编辑旧正文后保存时也需符合当前规则；完整归档恢复不批量转换旧内容，单日日志版本恢复沿用服务端保存校验。
