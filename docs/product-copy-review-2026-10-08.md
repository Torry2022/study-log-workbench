# 日常文案核查与修正

2026-10-08，接续“实例”与异常退出提示的修正。本轮只调整界面、可传到界面的错误文本及直接相关测试；不改变保存限制、数据格式、API 字段、模型模板或样式。

## 本轮结果

| 类别 | 修正 | 覆盖范围 |
| --- | --- | --- |
| 内部存储称呼 | “日块”按场景改为当前日志、当天日志或日志版本；日期说明使用“日期由系统维护” | 网页与鸿蒙的阅读、编辑、删除、导出、历史版本、链接、统计、帮助；服务端相关错误 |
| 过时的设置入口 | 区分 Windows 桌面端“文件 → 模型设置”、浏览器本地启动入口“模型配置”和服务器管理员检查 | 各 AI 模块共用的功能说明 |
| 空提取结果 | 明确没有适合保存的随记属于正常结果，不要求用户必然补充材料或重试 | 网页与鸿蒙随记提取 |
| 实现细节 | 保存结果未确认时说明可重试、不会重复保存，不展示记录身份机制；材料已有内容与归纳结果使用直观标签 | 随记提取与保存 |
| 原因混用与字段泄漏 | 功能说明标题避免把所有故障说成缺少配置；具体说明分别表达缺模型、服务器版本不支持、读取失败。输入错误不展示 UUID、clientId、baseVersion 或 JSON 对象要求 | AI 功能说明、日志／随记／问答／分类／生成方案的可见错误 |

错误类型、错误码、参数名和校验条件保持不变。日志读取错误的识别列表与实际抛出的提示同步调整，避免修改文案后丢失既有分类。内部文件名、接口语义及历史验收记录不进行机械改名。
