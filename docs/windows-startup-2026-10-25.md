# Windows 启动反馈

本批已获维护者视觉确认，并于 2026-10-25 原位更新本机 Windows；未对外发布。Windows 客户端仅在通用版仓库维护；服务器模式按通用版 API 契约连接，不包含个人版服务器兼容改造。

启动窗在读取设置和启动本地服务之前显示。浅色窗口使用现有暖白画布，Logo 为白底；深色沿用现有主题。图形直接使用鸿蒙生成的四层启动 SVG，动画用 CSS 实现，并非直接运行 ArkUI 动画。窗口显示后才触发：300ms 后四片从窗口外汇聚，底板随后出现；上、下圆点与横线端点碰触时短促收紧并回弹，从各自接触边缘溅出一大一小两滴圆润水滴，约 340–460ms 散去，整体约 1 秒。水滴先挤压，拉出约 120ms 的短液颈，先拉长再收细分离，圆头朝前、液颈拖在后方，再沿飞行方向拉长，收成圆滴后逐渐缩小、淡出。两滴的方向与速度错开，上下两处也略有区别，减少整齐排列和末尾残点。上方接触向上外侧、下方向下外侧减速溅开，不折返或旋转翻飞。浅色水滴为 Logo 的珊瑚色和墨色，深色为对应珊瑚色和暖白，不增加其他颜色。系统减少动态效果时显示静态 Logo，取消汇聚、回弹和水滴。应用图标仍用暖白底，官网与开发历程资源保持原样。

水滴反馈已获维护者确认并同步至两版鸿蒙；本机安装及真机验证范围见[验收记录](../study-log-harmony/docs/testing/2026-10-25-launch-motion.md)。

接触检查使用共享 SVG 的圆点和线端轮廓标记，结合当帧图层位移计算两轮廓是否接触；接触时才设置水滴起点、方向并播放反冲。每处只触发一次，汇聚结束或减少动态效果时停止检查。没有另设定时撒花或上抛、落纸轨迹。

用户可见文案按真实阶段显示“正在准备工作台…”“正在读取学习记录…”“正在载入界面…”；服务器模式显示“正在连接服务器…”。阶段回调经隔离的 IPC 传给启动页，只更新文本。没有计时模拟进度或强制停留时长，主界面就绪后立即取代启动窗。重复启动聚焦当前启动窗；关闭按钮及 Windows 会话结束会阻止后续开窗，已启动的本地服务沿原生命周期退出。

性能调整包括按 PID 查询进程时间、用 DriveInfo 检查磁盘类型，以及为原子写入的新建空临时文件设置当前账户权限后再写入。已有文件及目录的权限策略、实例归属和异常恢复保护保留。偏好仅在内容变化后写入。

追加诊断发现各项系统检查反复初始化 PowerShell，单项约 1–3 秒，累计约 9 秒。目录和文件权限、磁盘类型、机器归属及进程时间检查现共用短期子进程，经私有管道发送固定操作名和 JSON 数据；不传入可执行脚本，不开网络端口。请求回复按标识匹配，失败或超时拒绝检查，空闲两秒后结束。运行锁的机器、账户、开机时间、进程开始时间以及服务写入前登记的条件保持。

## 验证

- 桌面完整测试 31 项通过，覆盖保存、退出、恢复、备份、权限与升级。Windows 权限测试比较新旧方法的 DACL，并验证继承的 Everyone 权限被移除；旧 CIM 时间戳仍正确识别存活工作进程。新增管道并发归属、特殊字符路径、失败后继续请求及空闲退出后再请求检查。
- 增加真实启动阶段顺序检查，重复启动已运行服务不会再报告准备阶段；相关事务退出、重启、备份恢复专项通过。
- 实际启动逐帧读取图层位移、碰拢收紧比例、水滴透明度及两轴形变，核对水滴在碰拢后出现、起点集中在上下两处接触边缘，具有短液颈分离、大小和速度差、扇形方向及挤压、伸长和收圆且小幅散开，形状无多边形裁切，方向朝各自接触处外侧且末段连续淡出；浅深色分别核对恰为对应 Logo 的两种颜色。减少动态效果、稳定状态及就绪即退出均通过。
- 使用隔离合成实例运行实际 `app.asar` 打包目录程序，检查初启、重开、可见文案更新、浅深色、减少动态效果、重复启动聚焦及小节标签 500 字重。启动早期、服务准备期关闭和系统会话结束均保留应保留的偏好，释放服务锁，未出现迟到的主窗口。
- 服务器路径用本机 HTTP 替身验证就绪后立即进入页面、连接失效回到选择页；不等同生产服务器或个人版兼容验收。

同机隔离样本中，最初完整启动约 22 秒，首轮候选约 12–13 秒，追加优化后的目录包约 6.0/6.4 秒；动效修正后的最终包约 5.8/5.6 秒，对应主窗口约 5.0/5.3 秒出现，首次可见反馈约 0.3 秒。完整启动时间包含测试程序启动与等待确认的开销。样本使用小型合成资料，时间受系统负载、文件权限检查和服务初始化影响，不代表所有机器或真实资料规模的性能。

追加候选通过实际 Windows 打包脚本和 electron-builder `--dir` 构建，复用当前已构建网页及版本一致的既有运行依赖，已核对 ASAR、平台辅助模块与启动资源。首轮目录包因复用的网页构建缺少 Next 依赖而启动失败，补齐同版本依赖后重新构建并完成全部六组检查；未修改产品检查绕过失败。未构建 NSIS 安装程序，未覆盖日常 Windows、安装鸿蒙设备、推送或发布。验证脚本为 `ops/electron/startup-smoke.mjs`；接受源码目录或打包程序路径及独立输出目录。
