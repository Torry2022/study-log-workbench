# Windows 启动反馈

本批为本地候选。Windows 客户端仅在通用版仓库维护；服务器模式按通用版 API 契约连接，不包含个人版服务器兼容改造。

启动窗在读取设置和启动本地服务之前显示。浅色窗口使用现有暖白画布，Logo 为白底；深色沿用现有主题。图形直接使用鸿蒙生成的四层启动 SVG，聚拢动画约 400ms，系统减少动态效果时停用。应用图标仍用暖白底，官网与开发历程资源保持原样。

用户可见文案按真实阶段显示“正在准备工作台…”“正在读取学习记录…”“正在载入界面…”；服务器模式显示“正在连接服务器…”。阶段回调经隔离的 IPC 传给启动页，只更新文本。没有计时模拟进度或强制停留时长，主界面就绪后立即取代启动窗。重复启动聚焦当前启动窗；关闭按钮及 Windows 会话结束会阻止后续开窗，已启动的本地服务沿原生命周期退出。

性能调整包括按 PID 查询进程时间、用 DriveInfo 检查磁盘类型，以及为原子写入的新建空临时文件设置当前账户权限后再写入。已有文件及目录的权限策略、实例归属和异常恢复保护保留。偏好仅在内容变化后写入。

## 验证

- 桌面完整测试 30 项通过，覆盖保存、退出、恢复、备份、权限与升级。Windows 权限测试比较新旧方法的 DACL，并验证继承的 Everyone 权限被移除；旧 CIM 时间戳仍正确识别存活工作进程。
- 增加真实启动阶段顺序检查，重复启动已运行服务不会再报告准备阶段；相关事务退出、重启、备份恢复专项通过。
- 使用隔离合成实例运行实际 `app.asar` 打包目录程序，检查初启、重开、可见文案更新、浅深色、减少动态效果、重复启动聚焦及小节标签 500 字重。启动早期、服务准备期关闭和系统会话结束均保留应保留的偏好，释放服务锁，未出现迟到的主窗口。
- 服务器路径用本机 HTTP 替身验证就绪后立即进入页面、连接失效回到选择页；不等同生产服务器或个人版兼容验收。

同机隔离样本中，修改前完整启动约 22 秒，最后两次打包程序约 12–13 秒，首次可见反馈约 0.3 秒。样本使用小型合成资料，时间受系统负载、文件权限检查和服务初始化影响，不代表所有机器或真实资料规模的性能。

候选复用已验证 Electron 运行时与当前已构建网页，按打包配置装配并核对 ASAR 与启动资源。未运行本批完整安装程序构建，未覆盖日常 Windows、安装鸿蒙设备、推送或发布。验证脚本为 `ops/electron/startup-smoke.mjs`；接受源码目录或打包程序路径及独立输出目录。
