## 从零安装

- `git archive HEAD` 解出 15,073,280 字节的完整源码副本；副本内没有 `.local`、`local.properties` 或签名配置。Web 与鸿蒙目录分别执行 `npm ci`。
- `npm run build` 的 Web 生产构建通过；鸿蒙 `npm run test:protocol` 为 200/200，通过本机 SDK 的 34 项无签名 HAP 构建任务。鸿蒙源码的临时常亮开关保持 `false`。
- 在副本中暂时注入本机已有、匹配公开包名及手机的调试签名，完成签名构建并还原工程配置。签名 HAP 的 SHA-256 为 `5E12EE250EE9A5EA5DAB9822AB934E9646B1097AEC2F4DC2ADE6AFB8BAD233D4`。手机真机覆盖安装两次均成功，安装前的连接状态和已保存日志在更新后仍可读。这是维护者签名试装，不是其他使用者自行配置证书的证据。
- 按 README 初始化全新实例，启动生产 Web；手机连接同一局域网内电脑的临时转发入口，不使用 USB 反向端口。明确启用局域网 HTTP 测试开关后登录成功，强停并重启 App 后自动恢复连接和已保存日志。该临时明文连接只承载随机测试密码与合成资料；尚未验证不同网络下的 HTTPS 反向代理。

## 修复后手机日志 AI 专项

同一 A 合成实例上，本地替身只开启写作／标注能力并拦截对应 AI 请求，限定日期与合成标记；普通读取及日块写入仍走真实实例，没有调用付费模型。手机输入合成材料后收到草稿，点击“追加到编辑器”时源文件 SHA-256 不变；显式保存后服务端读到 `SYNTHETIC_PHONE_GENERATED_BODY`。随后从当前日块发起重点标注，替身只给该标记添加 Markdown 加粗。首包装入手机时对照窗口虽出现在布局树，实际画面却仍是 AI 面板，无法点击“应用标注”；源码对照确认公开版漏迁个人版 `LogHighlightReview` 的 `zIndex(30)`。恢复该原有层级后，鸿蒙 200 项协议测试、签名构建与覆盖安装通过，HAP SHA-256 为 `FF90835CE6F5D0F0412C686E68051BFE9281D198B8C2649A1D423A830CA7297B`。手机截图中对照窗口显示原稿及高亮行，点击“应用标注”只改变编辑草稿、源文件不变；再显式保存后服务端正文出现加粗标记。最后在手机编辑器中恢复原合成日块并保存，源文件 SHA-256 回到 `B668146ED3472FFBD6667C0B4C1E3CC215A81F0D5D44A7DE05F5BCC07C3ED02D`；强停重启后只读到原小节。截图和测试替身保留在本机忽略目录。该专项证明手机真实界面与合成响应链路，不证明真实模型生成质量。

同包手机补查日志页日间／夜间终态和夜间 AI 生成面板弹出输入法的状态：页头、正文和底部导航在两种主题下均可见；夜间面板的“追加到编辑器”固定操作区位于键盘上方，输入焦点和面板标题保持可见。只聚焦了空材料框，没有输入或保存；随后关闭键盘与面板，主题恢复“跟随系统”，设置面板显示该项为当前选中。此为一台手机、一个页面和一种输入法的静态抽样，不替代 R5 的尺寸／主题／连续动效矩阵；A 源文件 SHA-256 保持 `B668146ED3472FFBD6667C0B4C1E3CC215A81F0D5D44A7DE05F5BCC07C3ED02D`。

## 未覆盖及已知限制

修复后的同一签名包也已装入平板和 PC，并在隔离 A 合成实例分别复测重点标注审阅：对照窗口可见，展开、还原、关闭、重新生成、应用到未保存草稿，以及离开时取消／放弃修改均通过。代理只返回固定合成标注，未调用付费模型；两端测试前后实例中的 Markdown 文件哈希一致，PC 最后回到原合成日志。个人版与公开版 `LogHighlightReview` 组件内容相同，公开版此前缺的是宿主浮层的层级。本项补充两端回归，不扩大为所有屏幕尺寸或真实模型质量验收。

- 手机关闭临时常亮的同一签名包在前台空闲时，以系统临时 15 秒超时触发 `INACTIVE Reason: TIMEOUT` 和 `SLEEP Reason: TIMEOUT`，`Last Screen Off` 更新；读取时手机已再次唤醒，系统超时恢复为原 600000 毫秒且无覆盖值。此项只证明本机候选包能按系统超时息屏，不代替其他设备或发行包。
- 手机图片**剪贴板粘贴**、各尺寸主题与动效组合尚未完成真机试装。曾尝试用 HDC 启动设备浏览器打开本机合成 PNG 以准备剪贴板输入，该命令被自动审批以 `blocked by policy` 拒绝，未执行，也未改用等价命令绕过；原生文件选择插图不等于图片粘贴。随记候选及日志 AI 的本地替身验证不证明真实模型质量。已从手机取回并校验本次 77 字节合成 PNG，随后仅按精确路径删除该下载文件并确认不存在；其他下载文件未动。
- 网页上传两张图片后，手机显示的是 8×8 像素合成图的放大点，不能据此评价真实照片的展示质量。
- 收藏创建后又改动标题，网页收藏卡仍保存原标题并显示“未找到”；这属于 README 已说明的标题变化后定位 ID 可能失效的限制，本次没有把它算作收藏跨设备同步失败。
- 未调用付费模型；既有 5 元预算已接近用尽。没有执行第三方使用者的独立证书配置、不同网络 HTTPS、跨版本升级或应用市场发布流程。
