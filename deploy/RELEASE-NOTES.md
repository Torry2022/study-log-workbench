# 学习日志工作台 0.1.0

0.1.0 是学习日志工作台的首个正式版本。它面向愿意用 Markdown 长期记录技术学习的人，把按日期写日志、整理零散想法、收藏重点、回看统计和基于既有记录提问放在同一个工作区。记录由使用者自己保存，可运行在 Windows 本机，也可部署到自己的服务器并由网页和鸿蒙客户端访问。

## 当前版本可以做什么

- **写与读日志**：按月份和日期组织 Markdown，支持浏览、源码、分屏、图片、内部链接、导出、历史版本和完整备份。
- **整理学习材料**：随记保存零散想法，收藏标记值得回看的段落，搜索可按标题、正文、术语和代码定位记录。
- **回看积累**：统计记录日期、数量和主题分布；配置模型后可由 AI 提出分类建议，再由使用者调整和保存。
- **结合记录使用 AI**：可从材料生成待审阅的日志草稿、提取重点和随记，并对已有日志提问。回答保留来源；复杂范围问题会分步取证，模型或工具能力不足时仍可使用普通 RAG。
- **按自己的环境运行**：Windows 版内置本地服务；自部署版提供 web、MCP 和维护工具镜像；鸿蒙客户端连接自部署服务器，使用同一份日志、随记、收藏、问答和统计数据。

本地工作台与自部署服务器各自保存数据，不会自动同步。桌面安装包、自部署服务和鸿蒙客户端也需要分别更新。

## 正式版收尾变化

- 网页与 Windows 统一工作区动效和加载反馈。切换模块、日期、日志详情及浏览／源码／分屏时保持内容稳定；慢请求、失败重试和快速切换不会让旧响应覆盖新选择。
- 收藏、随记和统计在后台刷新时保留已有结果；首次无内容时延迟显示加载状态，统计月份切换和刷新使用工具栏加载线。
- 分屏模式采用源码在左、浏览在右；源码编辑菜单在高度充足时完整展开，入口样式与编辑区一致。
- 日志月份、日期和正文读取减少重复解析并复用内容缓存；检索复用解析结果和 BM25 统计，并支持可选向量检索。
- 网页与 Windows 问答可在切换会话或模块后继续后台生成；长范围问题采用有界证据读取和来源校验。Agent 路径按模型能力启用，不绑定单一模型。
- 鸿蒙端继续使用同一后端协议，补入当前来源追问、分类和界面约定；回答生成期间可以离开问答模块，历史项显示运行状态。当前仍需等待该回答完成后再切换问答会话。
- Windows 可在确认旧进程及工作进程均已结束后恢复同次开机遗留的运行状态，同时保留真实占用、跨机器目录和未完成写入等保护。
- 应用 Logo、右侧工具栏、滚动区域和标题栏细节统一，现有阅读、编辑、备份和恢复流程保持不变。

## 下载与部署

### Windows

下载 `study-log-desktop-0.1.0-x64-setup.exe`。安装前保存内容并正常退出应用，选择原安装目录覆盖安装；已有学习记录、配置和历史版本保留。安装包尚未签名。

### 自部署服务器

下载 `study-log-server-0.1.0.zip`。升级前先创建完整备份，再将 `RELEASE_VERSION` 改为 `0.1.0` 并拉取三个配套镜像。

### 鸿蒙

附件 `study-log-harmony-0.1.0-unsigned.hap` 是由 v0.1.0 源码构建的未签名开发产物，便于核对和使用自己的应用身份重新签名；它不是可在所有设备上直接安装的通用包。签名、包名与 Profile 必须匹配，步骤见仓库中的 `study-log-harmony/README.md` 和 `docs/harmony-independent-install.md`。

本次附件通过协议测试和 release HAP 构建。由于公开仓库不包含签名材料，本次产物未做安装后的真机验收；既有维护者设备验证记录不能替代其他使用者的独立签名和安装。
