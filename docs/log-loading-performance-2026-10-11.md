# 日志读取与加载反馈同步

参考个人版提交 `2354d4b`，适配通用版拆分后的存储、工作区状态和阅读组件；没有整文件覆盖或修改参考仓。

## 修改

- 月份统计只解析日期结构；单日读取仅整理目标日正文。正文缓存复用现有按实际文件内容失效的解析缓存，保留其容量限制、Markdown 围栏识别、日期归属和重复日期校验。
- 通用版已有内容比较失效、请求取消及草稿离开保护，继续保留；新增请求完成标识，首帧及月份→日期→正文衔接均显示加载状态，旧请求不能覆盖新选择。
- 月份区提供加载、失败、重试反馈；标题、正文和大纲区分加载、失败与真实为空。正文就绪后展示实际目录，无标题时不留空栏。
- 初始化或读取失败期间禁用“今天”和新建入口；重试保留目标月份、日期。刷新时旧编辑器不充当已加载正文，未保存草稿仍由既有草稿保护管理。
- 网页和 Windows 内嵌网页共用实现；本轮不改鸿蒙、MCP、个人版或生产实例。

## 验证

- 日志读取、写入、搜索、历史策略专项测试 21/21 通过，包括围栏内分隔线、重复/无效日期，以及同长度、同修改时间的内容更新。
- `npm run typecheck` 与生产构建通过；最后一次生产构建也包含类型检查。
- 独立 Playwright 在 Chromium、WebKit、浅深色、1920px 桌面与 390px 手机共 8 组通过：分别延迟、阻断月份/日期/正文请求，检查首次打开、刷新、失败重试、无日期初始化、真实为空、无标题、快速切换和取消离开后的草稿。
- 桌面检查浏览、源码、分屏；手机沿用原有浏览/源码入口，没有新增手机分屏。初始化逐帧检查没有闪出正文空状态或“未选择日期”。无横向溢出、页面异常、模型调用或日志写入；测试后合成源文件逐字节不变。
- 实际查看浅深色、桌面/手机、失败/加载和分屏截图。截图等待有限淡入动画结束，避免把首个透明动画帧误判为空白。

复跑入口：`node ops/verify-log-loading.mjs`。它启动仅绑定回环地址、使用独立合成目录与测试鉴权的生产服务，不继承真实实例配置；证据保留在被 Git 忽略的 `.local/` 下。最终加载证据：`.local/log-loading-1791731345157/results.json`。

## 同资料性能比较

同一台机器、Node v23.8.0，6 个合成月文件、168 天、563,976 UTF-8 字节。存储对照使用修改前 `af02979` 的模块与修改后模块；每侧 5 个新进程，依次读取月份、日期列表、单日，每项随后重复 8 次。未清操作系统文件缓存。

| 操作 | 修改前首次中位数 | 修改后首次中位数 | 修改前重复中位数 | 修改后重复中位数 |
|---|---:|---:|---:|---:|
| 月份列表 | 689.35 ms | 382.26 ms | 286.86 ms | 4.73 ms |
| 日期列表 | 92.78 ms | 101.78 ms | 96.57 ms | 44.18 ms |
| 单日正文 | 55.94 ms | 3.98 ms | 51.60 ms | 2.60 ms |

日期与单日的首次读取发生在月份列表之后，不能称为各自独立冷启动。日期列表首次仍需读取全月摘要，本次没有可靠的首次提速；冷月份仍需解析日期结构。数据见 `.local/log-perf-before-final-20261011/results.json` 和 `.local/log-perf-after-final-20261011/results.json`。可用 `ops/benchmark-log-reads.mjs <绝对模块路径> <绝对隔离输出目录>` 复跑，旧模块仅调整相对导入路径以便读取同一组未修改的依赖。

另用相同资料、同一 Chromium、1920px、新服务及新浏览器上下文交替比较 3 次；登录不计入导航计时，导航到目标日志正文可见为止：

| 界面操作 | 修改前 | 修改后 |
|---|---:|---:|
| 新服务首次导航 | 1199.38 ms | 1215.64 ms |
| 重复导航 | 887.18 ms | 321.45 ms |
| 服务启动至 HTTP 就绪 | 1344.73 ms | 1738.71 ms |

首次界面导航未显示提速，重复导航约减少 64%。旧侧使用此前独立 standalone 服务包，新侧使用本地生产 `next start`，两者启动方式不同，因此服务就绪时间不能归因于本次代码，也不代表 Electron 冷启动。原始结果与方法见 `.local/log-navigation-perf-1791731802751/`；存储测量与界面测量均没有并行构建。
