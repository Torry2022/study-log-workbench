# 网页空状态文案

本表约束公开版网页的空状态。沿用现有图标、字号、位置与颜色，只调整文字，不增加欢迎页、引导步骤或额外按钮。

## 口径

- 标题说明当前状态，正文补充用途或一个可行操作；不使用“从第一篇开始”等口号，不用“先……再来……”训导使用者。
- 无资料、未选择、搜索无结果与加载失败各自表达；不把无统计数据写成用户没有学习。
- 对使用者称“日志”“小节”“历史问答”，不暴露“日块”“会话”“候选”等实现词。
- 短列表只给一句状态，不凑两行；保留已经清楚自然的“暂无历史问答”“本月暂无日志”等提示。
- 配置不可用单独说明，不混作空资料，也不承诺 AI 一定能给出有来源的答案。

## 模块正文

| 场景 | 标题 | 说明 |
| --- | --- | --- |
| 日志全空 | 暂无学习日志 | 点击“今天”，记下今天学到的内容。 |
| 日志未选择 | 未选择日志 | 选择一个日期，查看当天的学习内容。 |
| 已选日志无正文 | 暂无正文 | 切换到“源码”，写下这一天的学习内容。 |
| 随记全空 | 暂无随记 | 随手记下学习中的问题、想法或收获。 |
| 收藏全空 | 暂无收藏 | 在日志目录中点亮小节旁的星标，方便以后回看。 |
| 问答无日志 | 暂无可参考的日志 | 保存学习日志后，可以在这里提问并回看相关内容。 |
| 问答尚未提问 | 关于日志，你想了解什么？ | 输入问题，回答会附上相关日志，方便回看。 |
| 统计全空 | 暂无统计数据 | 记录日志后，可以查看学习记录的数量和主题分布。 |

本轮类型检查与生产构建通过；独立浏览器 20 组主模块空状态及脚本中的侧栏、搜索、分类、AI 前置条件、历史失败重试和首篇保存流程通过，证据 `.local\empty-copy-browser\report.json`。核看问答深色、收藏深色、随记窄屏浅色和写作侧栏的代表性截图，未调整布局。其余辅助空态完成源码复核，不将其记为独立操作验收。
