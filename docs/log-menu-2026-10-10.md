# 日志菜单重复入口与大纲关闭按钮

用户反馈：页面已展示大纲，“更多”仍提供大纲弹窗；右侧已有 AI 工具栏，“更多”又提供重复入口。宽屏大纲弹窗的关闭按钮呈现浏览器默认外观。

## 修正

共享 Web 的 `LogReader` 根据页面大纲的实际布局可见状态决定是否提供弹窗入口，不在 JavaScript 中再复制 CSS 的宽度断点。缩放恢复页面大纲时关闭重复弹窗；源码、分屏、窄屏及阅读模式仍可打开大纲。

桌面“更多”移除 AI 工具入口，直接使用原有右侧工具栏；手机宽度下右栏隐藏为抽屉，日志操作面板继续提供入口。没有剩余操作时隐藏“更多”，按钮移出工具栏的原有响应式阶段仍保留菜单。菜单按钮隐藏时关闭已打开的菜单，避免再次缩窄后突然出现旧菜单。

大纲关闭按钮补用共享 `button icon-only` 类，宽窄屏均为 40×40、居中图标、既有圆角与主题色。原来的完整关闭样式仅位于手机媒体规则内，是宽屏异常的原因。未改变正文、标题定位、收藏、存储或模型协议；Windows 继续使用同一 Web 实现。
