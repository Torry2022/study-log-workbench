# 学习日志工作台 0.1.0-rc.9

本次为 Windows x64 与 Linux amd64 服务器配套预发布。rc.8 的附件与镜像保留。2026-10-10 按维护者要求，将起步引导的视觉修正纳入 rc.9，替换 Windows 附件、服务器部署包、校验文件及 web 镜像；mcp 和 tools 镜像内容不变。2026-10-11 再按维护者要求纳入长日志的悬浮日期导航，同步替换 rc.9 附件及 web 镜像。

## 本次更新

- 补回个人版的悬浮日期导航：左侧日期列表滚出视口后，可直接切换上一篇／下一篇、搜索日期及定位小节；网页与 Windows 共用实现，保留未保存内容确认。

- 新建工作台提供可编辑、可删除的使用示例日志；随记、收藏、问答和统计补齐起步引导。已有记录不自动改写，删除示例后不会重建。
- 随记、收藏和问答的起步页统一阅读层级与内容宽度：随记展示写法示例，收藏按三步说明操作，问答按回顾、关联及继续探索展示示例问题；窄屏自动纵向排列，不自动保存示例或发送问题。
- 统计分类由 AI 提出领域与归类，审阅后保存，支持手动完善；无模型时保留基础统计，已有分类仍可维护。
- 网页与 Windows 统一悬浮滚动条和返回顶部，不预留空隙、不挤动内容；滚动条停滚约1秒后淡出，悬停、拖动或键盘聚焦时保持可见。右侧工具栏滚动后仍延伸到视口底部。
- 补齐共享使用帮助与工作区快捷键；源码编辑支持 Ctrl + Alt + 3／4／5／6 设置三级至六级标题，鼠标三击普通正文可切到源码。
- 日志删除后选择剩余记录或显示空状态；页面已有大纲时不重复提供弹窗，AI 工具入口归到既有右侧栏。大纲关闭按钮使用统一样式。
- Windows 修复系统重启后遗留运行状态的检查恢复，以及模型设置、日志历史版本和使用方式窗口取消时主界面闪烁；保留原有记录、配置和历史版本设置。
- 改善产品介绍与示例中 AI 功能的说明，展示生成草稿、整理重点、提取随记及带来源问答的具体用法。

## 安装与部署

已安装 rc.9 的用户不会收到同版本替换通知，请从本发布页重新下载安装包。

Windows 下载 `study-log-desktop-0.1.0-rc.9-x64-setup.exe`。安装前保存内容并正常退出应用，沿用原位置和已有学习记录。

服务器附件为 `study-log-server-0.1.0-rc.9.zip`；web、mcp、tools 使用同版本配套镜像。桌面更新不会更新服务器，也不会同步本地与服务器的记录。

验证范围见 `docs/release-rc9-2026-10-10.md` 及 `docs/compact-day-navigation-2026-10-10.md`；附件摘要见发布页的 `SHA256SUMS.txt`。
