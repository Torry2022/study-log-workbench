2026-11-19。通用版本地候选，基线 `f838da04`。本次调整包含鸿蒙首次连接、功能补配返回，以及共用的网页和 Windows 设置。个人版继续使用既有固定服务及 Pi。

## 实现与取舍

首次连接使用“欢迎 → 开始连接 → 填写 → 打开工作台”。欢迎交代应用名称、用途和连接后的去向；填写页保留白底 Logo、应用名称及返回。手机使用全页，桌面使用现有居中弹窗和遮罩。首次入口的“稍后连接”已移除；旧暂缓记录、明确断开和原连接恢复继续使用已有待连接页。

连接探测、凭据暂存、实例身份、原子提交和草稿保护继续由已有控制器负责。页面只调整入口和呈现。局域网 HTTP 继续由用户选择，整行可以切换。欢迎、填写和返回复用既有动效；键盘及系统安全区由表单宿主管理。

AI 设置中的实际问题是跨页面保存后的收尾缺失。日志生成、重点标注、随记提取、分类整理、知识问答共用设置入口，原页面及输入保持挂载。确认本次保存、核对实例及新修订、刷新能力后，从功能进入的设置返回原功能；从日常入口进入的设置保存后继续留在设置。响应待确认、其他写入者更新、刷新失败和页面销毁各有独立结果。

手机材料提取使用原生全屏层。此前设置在工作区根布局中，可能被该层遮住；设置现在使用同一原生内容层机制，由原设置面板继续处理返回、未保存确认和外部关闭。设置关闭后回到原材料提取页。

“功能状态”分别呈现模型、日志生成、重点标注、随记提取、领域整理、知识问答的配置状态。模板与检索依赖由部署者维护。摘要读取独立保存当前能力，失败或实例变化时清空旧摘要；配置状态与模型调用验证分开展示。实际画面还发现详情箭头与展开状态脱节，已将图标状态分支放回响应式组件正文，并在最新包核对。

Web / Windows 宽屏默认进入学习记录，手机保留分组入口。关于页增加实际桌面版本和当前地址；主题分区称“外观”。Windows 首次本地或远程选择及可选 AI 流程保留，HTTP 选择移入连接选项。五类功能订阅已确认设置保存后的状态刷新，保持原材料和问题草稿。
