# 原始日志检索

`LOG_ROOT` 和 `INDEX_ROOT` 必须显式指定为互不包含的绝对目录。日志为只读来源，向量缓存写入独立的 `INDEX_ROOT`。

关键词检索不需要模型配置或实例身份文件，也不创建向量缓存。启用向量检索时，`LOG_ROOT/.instance.json` 必须是初始化工具生成的有效实例身份文件；缺失或损坏会返回 `instance_identity_unavailable` 诊断并回退关键词检索。缓存身份包含实例 UUID、来源路径、端点哈希、模型、维度和切片版本。同路径更换实例 UUID 或将实例恢复至新路径都会重建缓存。

一个 `INDEX_ROOT` 只允许一个 MCP 进程使用。索引更新队列只在当前进程内串行化，原子重命名保障完整文件替换；它不提供跨进程互斥，不支持多个进程共享同一索引目录。

运行合成数据测试：`npm test`。测试使用本机 HTTP 模型替身，不访问付费模型或真实日志。
