# 0.1.6 发布准备

本版从已独立验收的 `b52cd61` 准备，新增问题编辑和任务库版本 3。根工程、Web、MCP、Windows 及鸿蒙统一为 0.1.6，鸿蒙版本码为 10600。0.1.5 的标签、镜像和附件保留，不用新内容覆盖。

## 当前状态

业务基线已完成网页问答、模块过渡、鸿蒙 DOM、任务与归档专项及签名候选的本地和统筹独立检查。网页实际问答 20 项、动效 16 项及展开／折叠历史检查通过；鸿蒙完整测试 383 项、双浏览器 DOM 各 3 项通过。上述证据属于 0.1.5 版本号的开发候选，不能替代 0.1.6 的最终产物验收。

本轮将重新构建 Windows、Web／MCP／tools 三镜像、服务器部署 ZIP 和鸿蒙 HAP，再核对源码、版本、签名及包内容。当前尚未构建最终产物，未创建远端标签、发布 Release 或安装设备；未调用付费模型。

## 兼容范围

受理首个编辑任务时，SQLite 任务库与任务写入在同一事务内升级到版本 3。0.1.6 tools 支持该版本的完整归档与恢复；旧版 Web／tools 应明确拒绝，而不能把编辑任务当作普通追加。服务器必须配套升级 Web 和 tools，MCP 同批使用 0.1.6。

更新前正常停止并备份。降级需要恢复升级前的完整备份，不直接用旧工具读取新任务库。新版本的归档、旧工具拒绝及 Windows／容器实际入口还需在最终产物中核对。

鸿蒙真机输入法、设备安装及其他使用者的签名安装不包含在已通过的本地检查中。用户可见变化与配套文件见[版本说明](../deploy/RELEASE-NOTES.md)。
