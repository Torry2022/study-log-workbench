# 技术学习者的每日学习记录

公开版首先服务愿意使用 Markdown 的技术学习者，帮助用户记录每日学习过程、保存可复习的知识，并找回过去的学习经历。终身学习是长期定位，当前不宣称已适用于所有学科或人群。

## 核心流程

记录 → 整理 → 找回与回顾。当天只有几句话也可以保存，不要求固定栏目、完整文章或先配置 AI。材料整理与个人学习经历分开：导入资料不代表用户已掌握知识或亲自完成实验。

| 模块 | 职责 |
| --- | --- |
| 日志 | 按日期留下学习内容、过程和自己的理解 |
| 随记 | 留下零散问题、想法和尚未整理的收获 |
| 收藏 | 标记值得再次阅读的日志小节 |
| 搜索与问答 | 从自己的记录找回内容，回答可回到来源 |
| 统计 | 查看记录日期、数量及主题分布，不评价掌握程度 |

## 首次使用顺序

1. 选择独立资料目录并设置访问密码，进入工作台。
2. 新建今天的日志，写几句话并保存；通过日期和搜索找回。
3. 需要时使用常规 Markdown 编辑操作整理代码、列表、表格与公式。
4. 可选配置模型，选择生成方案，从材料生成草稿，审阅后保存。
5. 区分日块历史、内容导出与整实例备份，定期将完整备份放到另一位置。

Windows 电脑优先使用[本地包](windows-portable.md)，无需另装 Node 或 Docker；源码／服务器运行见[部署文档](deployment.md)。鸿蒙继续连接显式配置的实例，不新增独立本地存储或同步。Windows 默认仅本机访问，不因此自动开放给局域网设备。

验收围绕首次记录、格式编辑、方案复用、找回与备份四条任务进行。多 Agent 审查只能提供源码缺陷、实际操作问题和体验假设，不代表陌生使用者或长期使用反馈。未执行的检查保留待验，不以扩大设备／主题矩阵代替收尾。

日期标题由系统维护，新增编辑入口提供正文及三级至六级标题。旧 H1／Setext 内容的保存行为不在本轮改变，其与业务大纲的兼容差异单独记录。三级标题继续承担主要小节、收藏和统计语义，不批量改写资料。

本轮不新增打卡、学习评分、任务管理、提醒、云同步或多用户服务；个人版仅作只读实现参考，不覆盖其文件。不推送、发布安装包或覆盖日常应用。
