# 0.1.3 发布记录

0.1.3 让问答在离开页面后仍可继续运行，并补齐刷新恢复和帮助内容。产品版本统一为 0.1.3；鸿蒙构建号为 10300。此前发布标签和附件保留。

## 本次能力

问答由服务端任务执行，切换会话、进入其他模块、刷新或重新打开客户端后，可以重新找到任务和结果。保存失败可只重试保存，也可明确停止任务。服务退出会保留中断状态和片段，不自动重放模型：Windows 远程模式关窗不停止远端服务器，本地模式退出会停止随应用运行的服务。

浏览、源码和分屏在同标签页刷新后恢复各自阅读位置，正文仍从服务器读取。帮助按使用场景整理现有快捷键，鸿蒙窄屏可滚动查看。RAG／Agent 的调用与能力开关沿用既有实现，没有在本次增加模型阶段。使用说明见[版本说明](../deploy/RELEASE-NOTES.md)，协议边界见[持久问答任务](rag-tasks.md)。

Web 607 项通过、3 项既有跳过；MCP 60/1；鸿蒙协议 306 项；运维 51/1；desktop 23 项；鸿蒙帮助边界 2 项。类型检查、Web 生产构建、Linux amd64 三镜像、Windows 安装器和鸿蒙 release 构建通过。此前帮助／刷新浏览器 22 组、问答 30 组和补充抽查已独验；本版 Windows 实际安装入口九组、帮助／刷新 22 组和容器持久任务十一组再次通过统筹独验，部署六组与 RAG 三组报告一并核对。所有本轮问答使用隔离合成资料与本机模型替身，未调用付费服务。

Windows 沿用原目录覆盖，无额外备份或卸载。安装器退出 0，5259 份候选安装文件逐一一致，原资料与配置 19 份文件安装前后及隔离检查后哈希不变。已验证远程关窗继续、本地退出停服、长等待取消、重开不重放与带来源结果读回。

鸿蒙未签名附件来自本版 release 构建；同源私有签名 debug 包在 QXS-W20 真实平板原位覆盖。持久任务列明流程、帮助宽屏与真实悬浮窄窗口浅深色已验。手机因锁屏未验，外部 HTTPS、独立使用者签名及其他设备的边界继续保留；平板悬浮窗口不冒充手机验收，调试签名不公开。

容器覆盖任务归档恢复、旧版拒绝新状态、收据去重、1／15／30 秒后取消、长等待后停服与重启。普通数据逐字节保持；任务库恢复后按设计清除旧执行权，并检查完整性、任务与租约。具体脚本和协议见[部署](deployment.md)与[归档恢复](rag-tasks.md#归档恢复与回退)。
