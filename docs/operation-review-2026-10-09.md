# 记录、整理与找回的操作衔接

本轮接续已完成的整体适用性核查，不重新扩大设备或真实模型样本。公开版本仍为 rc.7，维护者已安装的本地修正版与公开附件分开记录。

## 已确认问题与修正

- 统计页说明重复为“按日志日志”；改为按记录天数与日志小节回看学习结构。
- 有上月数据时，比较数字替换了“按三级标题计数”的说明。现在同时保留计数口径和比较；有普通段落却没有小节的月份，在原有空状态说明段落计入记录天数、三级标题计入小节数量。不要求补标题，不改日期存储或统计协议。
- 服务器部署指南仍链接 rc.6，而当前公开附件及配置已是 rc.7；公开下载入口同步到实际已发布版本。下一候选与公开下载分开说明。

## 有限实际流程

独立 Playwright 使用新的隔离合成记录，不读取日常应用配置，不调用付费模型。

| 流程 | 结果与依据 |
| --- | --- |
| 无标题短记录保存及重开 | 网页及 Electron 通过；普通段落不要求补 H3 |
| 全文搜索、仅标题范围及返回全文 | 正文标记可被默认搜索找到；切到 H3 范围无结果，返回全文后查询保留并定位原文 |
| 上月比较与小节空状态 | 当月 1 天记录、0 个小节仍显示 H3 计数说明；代表性宽窄窗口无横向溢出，截图已核看 |
| 标注审阅与中断 | 既有浏览器流程重跑通过，含晚到响应、切日／切模块、认证过期与原稿保留 |
| 生成草稿与保存 | 既有浏览器流程重跑通过，含离开确认、刷新、认证、晚到响应及窄屏预览 |
| 收藏来源变化 | 既有浏览器流程重跑通过，含定位、来源变化／失效、分类和错误处理；保留收藏内容 |
| 问答操作衔接 | 既有浏览器流程重跑通过，含来源跳转及返回、未发送问题保留、保存／重命名／删除失败和认证 |

新脚本 `ops/record-review-smoke.mjs` 同时支持独立 Chromium 与 Electron（可传最终 EXE），经过实际登录与编辑器入口。网页证据 `.local/record-review-web-1791513802544/report.json`；Electron 证据 `.local/record-review-electron-1791513848292/report.json`；四条浏览器流程 `.local/operation-review-1791513475023/report.json`。生产构建及类型检查通过，21 项统计／收藏／问答相关协议测试通过，日志位于 `.local/record-review-{build,typecheck,protocol}.log`。

测试初次启动早于构建结束，另有测试路径放进程序目录、Electron 分区会话与 Playwright 请求上下文不共享、原生 DPI 一像素取整问题。脚本改用独立临时目录、页面 fetch 和按实际窗口检查；不放宽保存、搜索或统计断言。失败日志保留，只有最终完整成功运行记为通过。

## 本轮不扩展

搜索范围已有按钮状态、悬停文字和无结果说明，本轮未发现需要新增入口的缺陷。标注密度、回答篇幅及真实使用者习惯仍是体验观察，复用上轮四类真实材料的有限结论；不新增提示词设置、截断规则或产品能力，也不称为真实用户反馈。

## 候选准备边界

本轮统一准备 rc.8 的本地产物，不修改公开 rc.7，不自动推送、发布或覆盖日常应用。Docker Desktop 启动出现 dockerInference 套接字访问错误，服务器镜像构建暂受环境阻挡；未恢复出厂设置、删除容器或清理镜像。Windows 和网页验证继续进行。
