## 整体适用性核查（已纳入 rc.6）

全模块现状、证据、修复与待验项见[整体核查清单](generality-audit-2026-10-08.md)。此前“迁移完成”“五批实现完成”只表示列明实现完成，不等于通用性或所有使用体验通过。

- 已检查：首次使用、日志编辑、生成与方案、标注、随记提取／管理、收藏来源、搜索问答、分类统计、材料导入、导出、日志历史版本、完整备份及跨端启动和模板升级。
- 已修复：两端标注说明仍偏技术、问答提示词中的学科限制、已发布默认标注模板无法自动获得修正；另修复模拟器核查发现的鸿蒙窗口监听启动异常。真实样本追加修正问答无关补充／脚注倾向和提取过碎，提取模板也纳入精确升级。复用现有界面和业务机制，没有新增设置或模板管理。
- 已验证：类型／生产构建、服务与模板升级协议、独立 Web／Electron Playwright、实际打包运行时的本地记录与归档恢复、关键词问答协议、授权平板模拟器标注保存并由网页读回。失败和跳过的实际范围见核查清单。
- 尚待验证：真实模型的长期稳定性及更广材料表现（本轮四类有限样本已复核，见[质量记录](default-quality-2026-10-08.md)）；真实使用者体验及下方独立签名、外部 HTTPS、明确版本升级条件。

核查修正已纳入 rc.6，最终打包与隔离验证通过；未改 rc.5 标签或附件，未覆盖日常应用。

## 上轮交付结果（历史范围）

1. 当前入口统一：Windows 使用桌面安装包；服务器使用公开 rc.5 部署附件；鸿蒙按客户端 README 构建并连接自部署实例。历史浏览器本地包不再作为优先入口。
2. 从 GitHub 实际下载服务器 ZIP 并核对 SHA-256，使用解压后的 Compose 完成六组隔离部署检查。另建实例完成网页实际保存 → app-login/Bearer API 读取与修改 → 网页重新登录读回；过期版本写入返回 409。见 [本轮交付记录](public-delivery-2026-10-08.md)。
3. 鸿蒙按文档补装 npm 依赖后，224 项协议测试通过；编辑器 2 项测试通过，源码重新构建与已提交产物无差异；客户端 clean assembleHap 成功，默认无签名、临时常亮为 false。复用本机 SDK 和构建依赖，不冒称陌生使用者独立安装通过。
4. 发布范围维持 rc.5。该轮没有产品代码修复，不新增 rc.6，不改写 rc.5 附件。
