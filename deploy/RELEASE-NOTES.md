# 学习日志工作台 0.1.2

这次主要改善围绕已有日志的问答，以及网页、Windows 和鸿蒙上的内部链接选择。原有 Markdown 记录、配置和历史版本可以继续使用。

工作台按日期保存学习记录，也提供随记、收藏、搜索和统计。接入 AI 后，可以整理学习材料、提取重点，并围绕自己的日志提问，沿着来源回看原文。Windows 支持本地使用或连接服务器；网页和鸿蒙可以共用服务器上的资料。本地与服务器资料不会自动同步。

## 这次改了什么

- 问答可以根据已有材料决定直接回答、补读原文或继续搜索。材料充分时直接交付，确有缺口时才进入 Agent 补查；读取次数和整轮时间都有上限。
- 已知完整日期范围继续按范围读取，精确查找继续使用原有路径。超出输入容量的材料可分批处理，但长范围综合和生成表述仍有局限，回答应结合引用原文阅读。
- 调整问答标题与输入区布局，减少长会话中的位移。
- 网页和鸿蒙的内部链接选择器支持标题、大小写及日期筛选，候选分页加载；切换条件或关闭窗口会取消所属读取，避免旧结果覆盖新选择。
- 修复鸿蒙窄屏链接窗口搜索区挤占列表高度的问题。

## 使用 Agent

问答仍需配置聊天模型和只读 MCP。Agent 总开关默认允许，但只有显式设置 `RAG_AGENT_TOOL_CALLING_VERIFIED=true`、确认当前模型支持工具调用后才使用按需路径；未确认时正常使用普通 RAG。更换模型或接口后须重新确认能力。Jev 和范围末状态核对仍是默认关闭的实验功能。

配置方法与当前能力边界见[AI 配置](https://github.com/Torry2022/study-log-workbench-public/blob/main/docs/ai-configuration.md)和[问答架构](https://github.com/Torry2022/study-log-workbench-public/blob/main/docs/rag-architecture.md)。

## 下载与升级

- **Windows**：下载 `study-log-desktop-0.1.2-x64-setup.exe`，保存编辑内容并正常退出后，在原目录覆盖安装。安装包尚未签名。
- **服务器**：下载 `study-log-server-0.1.2.zip`。升级前创建完整备份，将 `RELEASE_VERSION` 改为 `0.1.2`，拉取配套镜像并重建容器；无需在服务器构建源码。
- **鸿蒙**：提供 `study-log-harmony-0.1.2-unsigned.hap` 和源码，需要使用者配置自己的匹配签名。未签名附件不能直接当作通用侧载包；设备与网络验收范围见仓库发布记录。

三个 Linux amd64 镜像使用统一标签 `0.1.2`，前缀为 `crpi-2sv5e1hzpqiwbovs.cn-qingdao.personal.cr.aliyuncs.com/study-log-public`。安装和部署前可用 `SHA256SUMS.txt` 核对附件。
