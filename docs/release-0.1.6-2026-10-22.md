# 0.1.6 发布记录

本版新增问题编辑和任务库版本 3。产品构建基线为 `655f2b1`，后续仅更新发布文档与部署 ZIP，不改产品源码。根工程、Web、MCP、Windows 及鸿蒙统一为 0.1.6，鸿蒙版本码为 10600。0.1.5 的标签、镜像和附件保留，不用新内容覆盖。

## 当前状态

业务基线已通过网页实际问答 20 项、动效 16 项、展开／折叠历史及统筹独立检查；鸿蒙完整测试 383 项、双浏览器 DOM 各 3 项通过。0.1.6 的 Windows 生产构建与类型检查通过，实际打包 EXE 的远程／本地任务、原位编辑、取消、退出与重开共 10 项通过；安装器中 5259 个应用文件与已测程序一致。

三份 Linux amd64 镜像以非 root 运行，实际任务生命周期与独立 SQLite 3 专项通过。鸿蒙 release 签名候选的 430 份源码、92 份 rawfile、编译载荷、应用身份和签名已由统筹独立核对，并完成平板中文输入法检查。当前等待统筹完成最后的 EXE／容器独验和正式发布放行，尚未创建远端标签或公开 Release；本轮未覆盖日常 Windows 安装、写入真实日志或调用付费模型。

## 兼容范围

受理首个编辑任务时，SQLite 任务库与任务写入在同一事务内升级到版本 3。0.1.6 tools 的完整归档与恢复已用实际容器和 Windows 打包工具核对；任务各列和 JSON 收据保留。归档内原始 SQLite 文件与源文件摘要一致；恢复事务会更新 SQLite 头部计数，不将整文件摘要变化误判为内容丢失。

0.1.5 tools 明确拒绝恢复该任务库，旧 Web 在启动时明确要求更新，源数据不变；换回新 Web 后不重放模型。服务器须配套升级 Web 和 tools，MCP 同批使用 0.1.6。更新前正常停止并备份，降级需恢复升级前的完整备份。

平板检查不替代全部手机、网络条件或其他使用者的签名安装验收。Windows 安装器未签名，公开鸿蒙 HAP 需要使用者自行签名。用户可见变化与配套文件见[版本说明](../deploy/RELEASE-NOTES.md)。
