# 学习日志工作台 0.1.0

学习日志工作台发布第一个正式版本了。

这个工具用来记下每天学到的东西：读懂的概念、试过的代码、排查问题时的发现，以及还没想明白的疑问。日志按日期保存为 Markdown，以后可以沿着日期回看，也可以通过搜索、收藏和问答找回当时的记录。

0.1.0 提供 Windows 桌面版、自部署网页版和鸿蒙客户端。你可以把记录保存在自己的电脑上，也可以部署到自己的服务器，让网页和鸿蒙客户端访问同一份资料。

## 从记录到回顾

写日志时，可以直接编辑 Markdown，也可以分屏，一边写一边看效果。代码、公式、表格和图片都能放进正文；保存过的内容可以通过历史版本找回，记录和附件也可以导出或做完整备份。

不适合写成长篇日志的想法，可以单独记成随记。日志里值得回看的小节，可以点星标收藏并分组。积累多了以后，用搜索找术语、代码或某段经历，用统计回看自己记录过哪些主题。

接入 AI 后，可以把课程笔记、阅读材料或项目记录整理成日志草稿，提取重点和随记，再由你审阅、修改和保存。回顾时也可以直接问：“我当时是怎么解决这个问题的？”“这个月主要学了什么？”回答会附上相关日志的来源，方便回到原文查看。需要跨日期查找或材料较多时，问答会分步读取和整理记录；这部分使用 RAG 和 Agent，并根据所配置模型的能力运行。

首次打开工作台会有一篇可编辑的示例日志，介绍常用操作和 Markdown 写法，方便从第一篇记录开始。

本地工作台与自部署服务器各自保存数据，不会自动同步。桌面安装包、自部署服务和鸿蒙客户端也需要分别更新。

## 相比预发布版，这次改进了什么

- 切换模块、日期和编辑模式时，过渡更连贯。刷新收藏、随记和统计时会保留已有内容，减少页面闪空；加载失败后可以重试。
- 分屏调整为左侧源码、右侧预览。编辑菜单会按可用高度展开，窗口放得下时不再多出滚动条。
- 改善日志加载和检索速度，减少反复解析同一份记录；配置相应服务后也可以使用向量检索。
- 网页和 Windows 的问答可以在后台继续生成。等待回答时，可以切换会话或去其他模块，历史列表会显示运行状态；跨月提问和来源追问也做了修正。
- 鸿蒙端补齐相关问答和分类接口，生成回答时可以切换其他模块。切换到另一问答会话目前仍需等待当前回答完成。
- 修复 Windows 异常退出后可能无法重新打开的问题，并调整 Logo、右侧工具栏、标题栏和滚动区域的细节。

## 下载与部署

### Windows

下载 `study-log-desktop-0.1.0-x64-setup.exe`。安装前保存内容并正常退出应用，选择原安装目录覆盖安装；已有学习记录、配置和历史版本保留。安装包尚未签名。

### 网页与服务器

下载 `study-log-server-0.1.0.zip`，按附件中的说明部署。已有服务器升级前请先创建完整备份，再将 `RELEASE_VERSION` 改为 `0.1.0` 并拉取配套镜像。详细步骤见[部署指南](https://github.com/Torry2022/study-log-workbench-public/blob/main/deploy/README.md)。
