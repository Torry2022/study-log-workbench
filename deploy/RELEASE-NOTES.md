# 学习日志工作台 v0.1.5

## 改进

- 统一生成方案弹窗与现有弹窗的标题、图标和操作样式。
- 鸿蒙手机的日志 AI、随记编辑与提取、日志历史使用独立页面，统一返回方式；平板保留宽屏布局。
- 统一各模块侧栏标题，压缩收藏计数区域，完善生成方案选择样式。

## 修复

- 鸿蒙问答切换回答版本后正确定位到底部，保持输入框显隐状态。
- 鸿蒙问答可沿所选旧回答继续提问，已续问的回答固定所选版本。

- 修复日志搜索返回动效和 H3、Aa 按钮显示问题。
- 调整侧栏与横向列表的手势优先级，补齐收藏、随记等页面的下拉刷新，避免切换模块时反复刷新。
- 修复历史版本页与日志顶栏叠加、返回层级不清晰的问题。
- 修复深色模式下日志阅读器首次加载时可能闪白的问题。

## 安装

- Windows x64：`study-log-desktop-0.1.5-x64-setup.exe`，保存草稿并正常退出后覆盖安装。安装包尚未签名。
- 服务器：使用本部署包，将 `RELEASE_VERSION` 设为 `0.1.5` 后拉取配套镜像并重建容器。更新前按维护文档停止服务和备份；无需服务器构建。
- 鸿蒙：`study-log-harmony-0.1.5-unsigned.hap`，需要使用者自己的应用身份、证书和 Profile 签名。

配套镜像为 Linux amd64，Web、MCP、tools 使用 `0.1.5` 标签。下载后用 `SHA256SUMS.txt` 校验。
基础记录不需要模型；AI 功能仍需自行配置。客户端连接服务器，不提供本地与服务器资料自动同步。
