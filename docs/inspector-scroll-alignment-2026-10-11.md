# 右栏滚动与顶部边线

## 修复

- AI 生成与重点标注面板加 `overscroll-behavior-y: contain`，在顶端或底端继续滚轮操作时不再带动左侧日志。支持该 CSS 的浏览器使用原生行为；本机 Playwright WebKit 不支持该属性，因此仅为不支持的平台补滚轮边界处理，保留面板及内嵌文本框的正常滚动。
- 桌面并排布局（1181px 及以上）复用日志标题栏现有 `ResizeObserver` 的实际高度，通过工作区 CSS 变量同步右栏顶部高度，两条底边对齐。保留标题栏自适应换行，不新增观察器、不写死高度；手机抽屉和较窄窗口的上下布局沿用原规则。
- 不改变生成、标注、模型配置或日志内容。

## 验证

- 最终源码类型检查与生产构建通过。
- 独立 Chromium、WebKit 浅深色：1181/1280/1440/1920px，浏览/源码/分屏共 48 次底边几何检查通过，允许误差不超过 1px。1440px 下展开、收起标题栏高度不变；日志页已滚动时两栏底边仍对齐。
- 两种面板分别在顶端向上、底端向下滚动，共 16 次检查，页面滚动位置不变；面板内部仍可滚动，鼠标移到日志区后日志仍可滚动。
- 测试通过在实际面板内插入合成占位块制造滚动，无模型调用，无日志写入；测试后隔离资料内容不变。实际查看 Chromium 浅色重点标注和 WebKit 深色 AI 生成截图，顶部边线连续对齐。
- 首次 CSS-only 方案在 Chromium 通过、WebKit 失败；核实属性支持情况后添加兼容处理，再跑两种浏览器均通过。测试选择器也已限定日志标题栏，避免混入隐藏统计页；失败运行没有计为通过。
