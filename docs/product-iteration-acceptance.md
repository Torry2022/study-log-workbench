# 产品方向实施记录

本轮实现依据 [产品方向](product-direction.md)。以下为合成实例、本地构建和代理审查结果，不代表外部使用者反馈。个人版仓库只读；未推送、发布或覆盖日常设备应用。

## 网页 Markdown 编辑

复用 CodeMirror，日志源码日期行及随记正文／个人理解使用同一命令实现。提供正文、H3–H6、加粗、斜体、代码、列表、引用、表格、公式、链接及已有附件入口；宽窄屏共用菜单。日期由系统维护，不新增旧 H1／Setext 内容禁令。

- 命令测试 11／11 通过。
- 网页全量测试 304 项：301 通过、3 项既有平台条件跳过、0 失败；独立类型检查与生产构建通过。
- `ops/browser-markdown-edit.mjs` 在隔离合成实例通过日志与两个随记字段、格式转换、单次撤销／重做、选区、保存、中文组合输入起始阶段及 390px 菜单检查；宽窄截图已目视核对。
- 实际操作发现并修复：初始 compositionstart 尚未进入 CodeMirror composing 状态，改为同时检查 compositionStarted；鼠标打开菜单后 Escape 关闭行为补齐。
- H1／Setext 与现有业务目录、收藏、统计的语义差异仍是独立兼容议题，本轮没有重做存储结构。

## 日志生成方案

三个内置只读预设、现有默认模板与个人方案管理已接入网页。旧客户端不传方案标识仍读 generation.md；管理写入使用版本快照和写前备份，不把方案写入源码仓。

- 方案专项 18／18 通过：认证、只读保护、409 冲突、实例隔离、写前备份失败不改原文件，以及真实生成路由选用方案／省略标识兼容。
- `ops/browser-generation-presets.mjs` 真实 API 流程通过新增、复制、编辑、改名、默认、删除、冲突保留输入与刷新后对照再保存；390px 深色及桌面浅色截图已核对。浏览器生成响应使用合成替身。
- 共享的全量 Web 测试、类型检查和生产构建通过，结果同上。
- 三个预设各一次真实模型调用均返回草稿，未改日志字节、随记或备份；日常／实践保留未完成事项，概念样本明确教材身份，没有虚构亲历。不过概念样本增加了未标注的补充术语及泛化的溢出解释，仍需审阅，不能宣称严格只转述材料。详见 [模型记录](model-validation.md)。
