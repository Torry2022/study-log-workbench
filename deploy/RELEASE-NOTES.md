# 学习日志工作台 0.1.4

学习日志工作台把每天读过的材料、实践中的发现和还没想明白的问题，保存在按日期组织的 Markdown 中。你可以从日期和标题回看记录，用搜索找回术语或代码，把值得反复看的小节加入收藏，也可以用随记保存零散想法。

Windows 版适合在自己的电脑上使用；网页和鸿蒙客户端可以连接自己部署的服务器。本地与服务器的资料不会自动同步。接入模型后，还能整理日志草稿、提取随记、标出重点，并围绕已有学习记录提问、查看回答的来源。

## 这次更新

- **回答的操作回到对应内容下方。** 来源、复制和重新生成放在各条回答底部；同一个问题重新生成后，可以用左右箭头查看不同版本。
- **生成过程更连贯。** 正文陆续显示，保存和复制始终使用已收到的完整内容。往上翻阅时不会被拉回底部，回到底部后继续跟随；切到其他模块，后台任务仍会运行。
- **阅读和编辑少些跳动。** 保存后保留编辑位置，切回浏览及退出阅读模式时衔接更稳定，大纲跳转也会避开固定标题栏。
- **鸿蒙问答与边栏更紧凑。** 调整回答操作、示例问题和抽屉排布，统一边栏层级，减少输入区下方的多余留白，并修正仅换行符不同导致的未保存提示。

服务器正常退出会中断尚在执行的任务，保留状态与已收到的片段；重开后不会自动重放这次模型请求。这不等于关闭本地服务后还能继续生成。Windows 远程模式关闭窗口不会停止远端服务器，本地模式退出会停止随应用运行的服务。

问答仍需配置聊天模型和只读 MCP。Agent 总开关默认允许，但只有显式设置 `RAG_AGENT_TOOL_CALLING_VERIFIED=true`、确认当前模型支持工具调用后才使用按需路径；未确认时使用普通 RAG。Jev 和范围末状态核对仍是默认关闭的实验功能。配置与能力边界见[AI 配置](https://github.com/Torry2022/study-log-workbench-public/blob/main/docs/ai-configuration.md)和[问答架构](https://github.com/Torry2022/study-log-workbench-public/blob/main/docs/rag-architecture.md)。

## 安装和升级

- **Windows**：下载 `study-log-desktop-0.1.4-x64-setup.exe`，保存正在编辑的内容并正常退出，然后在原目录覆盖安装。学习资料和配置保存在安装目录之外。安装包尚未签名。
- **服务器**：下载 `study-log-server-0.1.4.zip`。先按维护说明停止服务并创建完整备份，再把 `RELEASE_VERSION` 改为 `0.1.4`，拉取配套镜像并重新创建容器；无需在服务器构建源码。
- **鸿蒙**：提供 `study-log-harmony-0.1.4-unsigned.hap` 和源码，需要使用自己的应用身份、证书与 Profile 签名。未签名附件不能直接安装到设备，维护者调试签名包不公开。

含问答任务库的新归档需要本版配套维护工具。恢复会保留消息、完整结果和收据，但把旧的执行及等待任务标为中断，不自动重新调用模型。旧工具会拒绝新归档格式；不要让旧版 Web 改写已有新任务状态的实例。完整备份与某一天的日志历史版本是不同功能，具体操作见随包说明和仓库维护文档。

三个 Linux amd64 镜像使用统一标签 `0.1.4`，前缀为 `crpi-2sv5e1hzpqiwbovs.cn-qingdao.personal.cr.aliyuncs.com/study-log-public`。用 `SHA256SUMS.txt` 核对下载的附件。此前版本保留，设备、网络及升级的实际验证范围以仓库发布记录为准。
