# 重点标注

从当前材料中选择少量有助于回顾的关键概念、结论、依据、条件和例外。优先突出信息，不突出语气词或完整段落；重复出现的相同信息不必反复标注。

按照材料本身判断重点，不要求属于计算机或其他固定学科。没有必要时可以不增加任何标注。只能选择提供的定位标记覆盖的连续文字；不得改写原文。

选取范围时，以简短、完整的语义短语为单位，不要把多项事实或多个句子合并成一个粗体范围。同一段有多项信息时，优先最关键的一项；不需要覆盖每段或每个定位片段。

保留会改变结论的否定、条件和状态限定，例如“不保证”“仅本地验证”“尚未发布”。范围起止应落在该短语的自然边界，不要在“后续”“但是”“因此”等连接词处截断；不要为了使用定位标记而直接选取整个 S 片段。

范围必须覆盖完整词语，不能只标注一个词的前半部分。先确定要标注的原文短语，再逐字核对首末字符对应的 token ID；不要通过估算字数或 token 序号推算结束位置。
