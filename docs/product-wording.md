# 产品用词

当前界面、README 和使用说明使用以下口径，避免用“资料”同时指路径、学习记录、模型输入和完整实例。

| 对象 | 用词 | 示例 |
| --- | --- | --- |
| 文件夹路径 | 保存位置、保存文件夹 | 选择保存位置、打开保存文件夹 |
| 当前使用方式 | 本地使用；远端显示服务器地址 | 标题栏用于区分当前连接，不表示目录名称 |
| 用户记录的内容 | 学习记录；明确模块时用日志、随记 | 打开已有学习记录 |
| 图片等附属文件 | 附件 | 日志、随记和附件保存在这个文件夹中 |
| 送给模型的文章、笔记、代码 | 学习材料 | 导入学习材料 |
| 记录、附件、配置及历史版本的归档 | 完整备份 | 创建完整备份、从备份恢复 |
| 部署和维护的存储单位 | 实例、实例目录 | 一个实例包含记录、附件及运行配置 |

“学习记录”不包括密钥和运行配置。介绍完整备份时应说明其包含配置与凭据，不能只称“日志备份”。错误提示应指出相关记录或文件，不改变错误码和协议字段。

历史验收记录保留当时的菜单名称和证据；当前使用说明采用新名称。测试材料、引用原文及模型内部提示中的“资料”按原义保留，不进行全仓库机械替换。

2026-10-08 核查覆盖 Windows 桌面与浏览器启动入口、网页可见提示、鸿蒙主代码与资源、README、部署及备份使用说明。鸿蒙界面未发现需要替换的同类用词；其接收的服务端提示随网页服务更新。
