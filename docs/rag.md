# 日志问答

问答只引用当前实例的日志原文。`logs_only` 限于日志证据；`logs_and_general` 把通用知识补充与日志依据分开。随记与 Wiki 不参与检索。

检索规则保留日期范围、时间线总结、对比与原文定位；明确写出两个日志日期并用“与／和／及／、”连接时，检索范围包含两天，不因先匹配到首日而丢掉次日；无效日期不得自动滚到下月。原文定位保留用户输入的全角字符。引用按回答首次出现顺序编号，代码、链接及 HTML 中的引用样式文本保持原样；缺少引用时给出来源提示。

检索规划、回答规范化与服务端传输的 40 项测试通过。包括真实 MCP SDK 联通、旧协议握手、取消、超时、断流与供应商错误脱敏。生产构建与类型检查通过；两种模式的真实模型小样本见[模型验收](model-validation.md)。

## 配置与问答接口

Web 显式配置 `STUDY_LOG_MCP_URL`（完整 HTTP(S) 接口地址）和 `STUDY_LOG_MCP_TOKEN`，以及聊天配置。没有默认远程服务。能力接口只检查本地配置完整性，不代表远程连接可用。MCP 返回的日期、文件归属、标题位置、内容摘要和大小在 Web 边界再次校验。

`POST /api/rag/query` 接收 `question`、`mode` 和可选 `history`。SSE 事件为 `status`、`sources`、`delta`、`done`、`error`。只有 `done` 表示完整回答；错误或连接提前结束不得当作成功保存。客户端取消会传递给检索和模型请求。无日志依据的 `logs_only` 请求直接给出说明，不调用回答模型。

## 历史存储

会话保存在实例的 `state/rag-sessions.json`，写前完整快照存入 `BACKUP_ROOT/rag-sessions/`。读取遇到损坏 JSON 或结构异常会报错，不会当作空历史覆盖。写入经过单进程串行队列、独占临时文件、同步落盘与原子替换；实例服务锁限制同一数据目录的 Web 写进程。

每个会话有独立版本。创建使用客户端稳定 UUID，修改携带版本和操作 UUID；响应丢失可用原请求重试，冲突保留客户端内容。删除留下最小操作凭据，迟到的创建不能复活已删除会话。停止和失败回答保留实际状态，未结束的流不能入库。自动标题在调用模型前检查是否仍为默认标题，完成后再次核对版本；手动标题优先。

17 项临时实例存储测试通过，包括并发冲突、幂等重试、删除防复活、损坏文件保护、写入失败、备份及 Windows 目录联接边界。真实 HTTP 路由测试 9 项通过，模型为本机替身。

`GET/POST /api/rag/sessions` 查询和创建历史；`GET/PUT/PATCH/DELETE /api/rag/sessions/:id` 分别读取、保存完整对话、手动命名和删除。创建携带 `id`、`mutationId`、`baseVersion:null`、`answerMode`、`messages`；修改和删除携带现有版本与新的操作标识。列表的 `q` 搜索标题和全部用户问题。`POST /api/rag/sessions/:id/title` 携带 `baseVersion`，仅为默认标题生成短标题。所有响应禁止缓存；版本冲突为 409，存储异常不会清空历史。

## 工作区与失败恢复

`useRag` 管理问题、消息、流式请求、当前会话及未确认的保存快照。只有完整回答才自动保存历史；中断、停止、登录过期保留已收到的内容和实际状态。保存失败或损坏的成功响应保留同一快照、会话和操作 UUID；重试不会新增重复会话。冲突时可以保留内容，或明确放弃后重新读取。重命名和删除也保留未确认操作身份。

离开或刷新保护未提交问题和未保存回答。认证过期只隐藏工作区，重登保留内容；显式退出按正常离开规则清理。切换回答范围决定下一次回答的模式，随该次完整对话保存，不额外触发模型调用。

桌面历史侧栏贴住视口，列表独立滚动；折叠弹层覆盖正文并可操作。打开历史从对话顶部开始，新问题和流式输出才自动跟随。展开、折叠弹层和手机抽屉均定位当前会话；内部定位不会滚动整个页面。引用展开保存的原始片段，返回真实日志前核对日期及标题位置；标题变化时退到日块并说明，允许返回问答原阅读位置。复制回答时保留代码中的引用样式文本。

`node ops/browser-rag.mjs 合成实例绝对路径 本机URL [chromium|webkit|firefox]` 使用本机流式模型替身和真实会话 API。2026-09-22 在最终生产构建通过 Chromium 与 WebKit 全套：23 条历史下的独立滚动、当前项可见性、全历史搜索、手机抽屉、引用往返、未提交问题保护、401、EOF/停止、迟到响应、重命名/删除错误，以及三次相同保存快照的失败/损坏响应/成功重试。桌面和手机截图已检查。Firefox 引擎未安装，未验证。
