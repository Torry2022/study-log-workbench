## 版本与兼容

根工程、Web、MCP、Windows 均使用 0.2.0；鸿蒙使用 0.2.0 / 20000，应用身份保持原值。接口契约版本不变，任务库仍使用已有版本 2／3 规则，未引入新的数据库格式。版本 3 由编辑问题任务按已有逻辑启用。

本批配套 Windows 安装包、鸿蒙未签名 HAP、Linux amd64 Web／MCP／tools 镜像与服务器部署 ZIP。旧版本产物保留，升级前正常停止并创建完整备份。
