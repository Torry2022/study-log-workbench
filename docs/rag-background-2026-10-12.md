# 问答在应用内继续生成

生成和保存绑定会话 ID，不再绑定当前页面。网页与 Windows 的共享工作台可在生成期间切换历史、新建另一个问答，或进入日志/随记等模块；当前视图只展示所选会话，其他请求继续处理自己的消息。完成后按原 ID 保存，不跳转当前页面或把回答写进另一会话。

## 状态与保存边界

- 第一问发送前分配本地会话 ID，并立即进入历史列表；完整 done 前不会把半条回答保存为历史。未保存的条目保留在当前工作台内，可重新打开。
- 各会话分别保留问题草稿、回答模式、消息、请求控制器、生成/保存状态、错误和待重试快照。同一会话正在生成、保存或结果未确认时不能重复提交；其他会话不受这一状态限制。
- 侧栏会话项显示生成/保存旋转图标、未保存提示和新回答标记，收起侧栏的历史浮层及手机历史抽屉复用相同状态。读取历史列表或列表报错时，已有活跃条目仍可见。保留既有尺寸和主题变量，减少动态效果时停止图标旋转。
- 停止只取消所选会话的请求，保留部分回答。保存失败保留原回答及相同 mutationId/baseVersion/body；重试不能生成另一条历史。延迟标题仍只合并已知的标题版本变化，不阻塞下一次提问或放宽版本冲突保护。
- 后台保存完成只更新自己的会话和历史行；打开会话清除新回答标记。离开只读且无草稿/活动的会话后释放正文缓存，后续打开重新读取服务器，避免无限积累阅读缓存。
- 意外登录失效取消请求，但保留草稿和回答；保存结果未知时提供重试/重新读取。活动切换期间的旧回调不能覆盖重新登录后的状态。主动退出则检查所有会话的未保存内容，取消退出不会停止任务，确认退出才放弃；浏览器/桌面关闭保护也按全体未保存状态判断。
- 快速切回已选会话会结束被取消的加载状态；重新读取仅针对当前会话，不能被另一会话的未确认重命名或删除操作改换目标。

本次是工作台仍打开时的请求和会话管理，不增加服务端持久任务队列；刷新页面或关闭应用后不承诺继续执行。后端 SSE、会话文件和调用额度保持。鸿蒙本轮未改、未现场验证。
