# 日志源日期与问答日历范围修复

2026-11-03，本地候选，未发布。此次修复来自隔离问答中可复现的两个问题：源文件的非零填充日期被并入前一个日期下，当前问题省略年份时未形成检索日期约束。未改原日志、题目或评分标准，未改提示词和模型参数。

## 源日期

原始 Markdown 二级日期标题接受 YYYY-M-D 和零填充写法，元数据统一为 YYYY-MM-DD；API 参数仍要求有效的标准日历日期。解析保留原始偏移和正文，读取不重写源文件。规范化后重复的日期及无效日历日期会拒绝读取，避免静默选取一份内容。

网页日期读取、目录和编辑入口同步；统计及 Wiki 的来源日期也按同一规范处理。个人版 MCP 小节和 Wiki 源解析同时修正长围栏内较短标记提前闭合的问题。编辑或删除仍走原有版本核对及结构分隔流程，邻日标题与正文保持，未迁移资料。

MCP 切片版本递增：个人版 3、通用版 4。旧切片配置失效，向量由原始资料重新建立；不能继续用带错误日期的旧索引代表修复结果。

## 问题中的日期

单独的中文月日使用已有的上海当前年份策略，支持中文数字、按顺序继承年份和省略月日枚举。原问题确定的约束保留到检索阶段，模型改写查询不能放宽；事件发布日期、原文字面检索与日志日期仍分开。无效数字按完整词元拒绝，保持原有日期范围 API 的形状。

此处只有日历语法处理，无项目名称、术语或评测题目分支，也未新增模型规划步骤。

## 验证

两版均补充源日期和日历范围回归，覆盖混合写法、CRLF 原始边界、代码围栏、日内目录、重复/无效日期、保存与删除，以及原问题日期在查询改写后的保留。独立只读回放核对了实际资料中全部 8 个非零填充标题：Web、MCP、切片和范围分页归属一致，源文件哈希不变；这是解析正确性的证据，不代替真实模型端到端验收。

两版类型检查和隔离生产构建通过。个人版620项RAG/Wiki等相关回归、追加439项相关复验和MCP66项通过；通用版全量网页744项通过、3项既有跳过，MCP64项通过、1项既有跳过。两版本机生产HTTP均按无年份中文日期查询得到标准日期引用及done；个人版另验证日历源读取、统计、重新生成幂等和容量收尾。这些检查均无外部API费用，真实模型12题单路验证另行冻结执行。生产仍使用原路径，Pi 保持关闭；本次没有部署或设备操作。

## 描述隔开的省略日期（追加修复）

当前问题中的日期之间可以有描述，例如“4月8日记的准备，和10日记的结果”。次日继承最近明确月份，不能只按紧邻日期列表识别；句末或换行结束继承，新出现的月份清除旧日的月份上下文。事件日、持续天数和序数继续分开，无效日不能回退成首日。原范围守卫保持，修复日期进入范围的位置；不改变提示或以题目词决定处理。
