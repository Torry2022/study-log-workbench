# 学习日志工作台 v0.1.6


## 新增

- 网页、Windows 与鸿蒙可直接编辑已保存的问题。新回答保存成功后替换该问题及后续对话；失败或停止时保留原对话和编辑稿。
- 用户问题支持复制，问答按实际问题时间显示分隔。

## 改进

- 切换会话或模块时保留问题编辑稿，与底部的新问题输入互不覆盖；显式取消才丢弃当前编辑稿。
- 问答历史刷新时保留已有列表，加载与失败提示不再挤动会话项。
- 网页模块切换保留原尺寸，以位移和淡入淡出衔接；统一侧栏导航名称，统计分类管理保留在侧栏。

## 修复

- 编辑与其他客户端的保存发生冲突时，保留草稿并提供重新读取；旧分支任务不能覆盖新对话。
- 修复 WebKit 中点击已聚焦的导出菜单项时，菜单提前关闭、导出未触发的问题。

## 下载与安装

下载后请使用配套的 `SHA256SUMS.txt` 校验。Windows 更新前保存草稿并正常退出；鸿蒙 HAP 需要自行签名。

| 平台 | 配套文件 |
| --- | --- |
| Windows x64 | `study-log-desktop-0.1.6-x64-setup.exe`，安装包未签名 |
| 服务器（Docker） | `study-log-server-0.1.6.zip`，配套 Linux amd64 Web、MCP、tools 镜像 |
| 鸿蒙 | `study-log-harmony-0.1.6-unsigned.hap`，需要自己的应用身份、证书和 Profile 签名 |

## 升级说明

- 更新前停止服务并创建完整备份。服务器请同时升级 Web 与 tools，使用配套的 `0.1.6` 部署文件和镜像。
- 首次受理编辑问题的任务时，任务库会升级到版本 3，旧版 Web 和 tools 将拒绝读取。需要降级时，应恢复升级前的完整备份，不能只换回旧程序。

**完整更新**：[v0.1.5 → v0.1.6](https://github.com/Torry2022/study-log-workbench-public/compare/v0.1.5...v0.1.6)。
