## H4 读取层当前进展

已对照公开 Web/API 的月份、日期列表和日块响应，建立鸿蒙端读取模型及请求层。它仅共享同一实例、同一登录会话中尚未完成的月份/日期列表请求；实例或会话切换、读取完成或失败后不复用旧结果，日块详情始终单独读取。8 项鸿蒙纯逻辑测试通过，其中 2 项覆盖旧实例迟到响应、重新登录、失败重试、同月并发和日期详情路由；无签名 HAP 编译通过。纯逻辑测试本身不证明设备阅读或编辑可用。

原生 Markdown 阅读组件及其离线脚本、样式、字体和许可证已迁入。个人版渲染器原来把图片接口固定在个人域名，公开版改为由当前实例地址生成图片 URL，只有当前实例的附件请求携带 App Token；跨实例切换后重新渲染。`node ops/harmony-reader-smoke.mjs` 在独立 Chromium 中验证标题、数学公式、当前实例图片、外部图片不带令牌，以及 A→B 图片地址和令牌切换。PC ArkWeb 的合成图片显示已另行实测，其他渲染内容及设备仍待复核。

连接成功后现在进入日志路径：月份、日期列表、日期小节定位和日块 Markdown 由公开服务读取；宽屏显示侧栏，窄屏使用日期导航层。读取响应有代次检查，快速切月/切日的旧结果不得覆盖当前选择；401 返回登录入口。无签名 HAP 编译通过。当前页面只供逐批迁移内部验证，尚无手机、平板或 PC 安装/视觉证据；完整顶部操作区和其他模块导航仍未接入，不能称作与个人版 UI/UX 对齐。

写入契约核对发现个人版旧控制器使用的保存方法及响应形状与公开 Web/API 不同。公开版已为 `PUT /logs/day`、`DELETE /logs/day` 建立原生请求入口，保留 `baseVersion`，409 `LOG_CONFLICT` 原样返回调用方；协议测试覆盖请求方法、正文/版本及冲突码。编辑器保存使用公开服务返回的完整 `{day}`，没有套用旧控制器对 `{result}` 的假设。

CodeMirror 源码编辑器及许可证已迁入，浏览器资源测试验证加载、合成输入和快照读取。页面现在支持浏览/源码切换与明确保存：提交当前编辑快照、保留写入期间继续输入的差异，409 显示冲突且不清除草稿；切日、切月或切换服务器前需要明确放弃未保存修改。独立合成实例通过 App Token 的创建、409、读回与删除闭环；该服务测试不代表鸿蒙设备上的编辑成功。图片插入、重启后草稿恢复以及完整原版工具栏仍待迁移和设备验收。

补查认证过期路径时发现页面卸载会丢失草稿。现于切回登录前捕获编辑器快照，并按实例命名空间暂存于当前进程；重新登录同一实例后优先打开原日期、恢复未保存正文，其他实例不接收该草稿。离开页面前也先取得编辑器快照，避免尚未推送的输入绕过未保存提示；编辑器的保存快捷键接到同一保存路径。可用的编辑器原生接口未暴露个人版的跨设备接续方法；随包的编辑器运行脚本保留原构建中的未调用分支，公开版没有接续入口。此措施覆盖当前进程内的 401 重登，进程结束后的持久草稿与真机输入法时序仍待后续批次验证。

日志导航已迁入个人版的“今天／选择日期／新建”与有记录日期跳转日历。新建日期先读取不存在的日块，用 `baseVersion:null` 在首次保存时创建；保存后重读月份和日期导航，使新日可见。日期切换仍经过未保存检查。该交互已完成无签名编译，实际弹层、输入法和新建保存尚需设备验收。

删除入口现按所见版本二次确认，未保存修改会在确认中明示；服务端确认删除后接收空日块并刷新导航，409 保留当前页面供核对。服务端 App Token 删除契约已由合成实例闭环验证，客户端交互仅完成无签名编译，设备上的确认框、删除后编辑器状态和失败恢复仍待验收。

备份恢复现使用公开服务的写入前日块版本列表、分页、预览和 `baseVersion`＋`backupVersion` 双版本恢复契约。旧个人版面板依赖每日任务和 OSS 状态，不能直接移入；公开版沿用其双栏差异查看器及许可证，重新接线当前实例的版本列表、预览和恢复确认。恢复前捕获编辑器最新快照，确认时明示未保存修改；409 要求重新预览，成功后以服务返回日块重置编辑器并刷新导航。9 项鸿蒙协议测试、查看器 Playwright 文本安全检查、合成实例 App Token 的列表→预览→过期冲突→重新预览→恢复→删除，以及无签名 HAP 构建通过。原生弹层、窄屏差异滚动、恢复后编辑器状态仍待手机、平板和 PC 验收；完整工具栏、图片及导入导出仍未迁完。
